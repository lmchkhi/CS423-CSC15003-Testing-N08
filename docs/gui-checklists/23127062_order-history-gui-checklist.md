# Checklist GUI Testing - Màn hình Lịch sử đơn hàng

## 1. Thông tin màn hình

- Screen / route: `Hồ sơ của bạn` và `Lịch sử đơn hàng` - `/profile`
- Mục tiêu: kiểm tra lịch sử đơn hàng theo những gì người dùng nhìn thấy: bảng đơn hàng, trạng thái rỗng, trạng thái tiếng Việt, màu sắc và giới hạn dữ liệu theo user đang đăng nhập.
