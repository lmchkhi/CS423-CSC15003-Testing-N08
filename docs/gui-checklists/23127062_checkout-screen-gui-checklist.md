# Checklist GUI Testing - Màn hình Thanh toán

## 1. Thông tin màn hình

- Screen / route: `Xác Nhận Đơn Hàng` - `/checkout`
- Mục tiêu: kiểm tra màn hình checkout theo những gì người dùng nhìn thấy: danh sách sản phẩm, tổng tiền, mã giảm giá, nút xác nhận, trạng thái xử lý và màn hình thành công.
