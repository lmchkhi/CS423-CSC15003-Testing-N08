# TC-FR-24-009: Đăng ký với Mật khẩu thiếu chữ hoa

## Requirement ID
FR-24

## Module / Test type / Technique
Register / Functional / Domain Testing

## Preconditions
- User chưa có tài khoản trong hệ thống
- User đang ở màn hình Đăng ký

## Test data
| Field | Value |
|---|---|
| Họ Tên | Nguyễn Văn A |
| Email | user05@gmail.com |
| Mật khẩu | abcd@1234 |
| Xác nhận mật khẩu | abcd@1234 |

## Test steps
1. Mở màn hình Đăng ký
2. Nhập Họ Tên: `Nguyễn Văn A`
3. Nhập Email: `user05@gmail.com`
4. Nhập Mật khẩu: `abcd@1234` (không có chữ hoa)
5. Nhập Xác nhận mật khẩu: `abcd@1234`
6. Bấm nút Đăng ký

## Expected result
Hệ thống hiển thị thông báo lỗi mật khẩu phải có ít nhất 1 chữ hoa. Không thực hiện đăng ký.
