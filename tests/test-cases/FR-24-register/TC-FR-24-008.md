# TC-FR-24-008: Đăng ký với Mật khẩu quá ngắn (< 8 ký tự)

## Requirement ID
FR-24

## Module / Test type / Technique
Register / Functional / Domain Testing

## Preconditions
- User chưa có tài khoản trong hệ thống
- User đang ở màn hình Đăng ký

## Test data
| Field | Value |
|---|---|
| Họ Tên | Nguyễn Văn A |
| Email | user04@gmail.com |
| Mật khẩu | Ab@12 |
| Xác nhận mật khẩu | Ab@12 |

## Test steps
1. Mở màn hình Đăng ký
2. Nhập Họ Tên: `Nguyễn Văn A`
3. Nhập Email: `user04@gmail.com`
4. Nhập Mật khẩu: `Ab@12` (5 ký tự, < 8)
5. Nhập Xác nhận mật khẩu: `Ab@12`
6. Bấm nút Đăng ký

## Expected result
Hệ thống hiển thị thông báo lỗi mật khẩu phải có tối thiểu 8 ký tự. Không thực hiện đăng ký.
