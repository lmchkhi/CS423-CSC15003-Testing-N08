# TC-FR-01-001: Đăng ký thành công với dữ liệu hợp lệ

## Requirement ID
FR-01

## Module / Test type / Technique
Register / Functional / Domain Testing

## Preconditions
- User chưa có tài khoản trong hệ thống
- User đang ở trang Đăng ký

## Test data
| Field | Value |
|---|---|
| Họ Tên | Nguyễn Văn A |
| Email | user01@gmail.com |
| Mật khẩu | Abcd@1234 |
| Xác nhận mật khẩu | Abcd@1234 |

## Test steps
1. Mở trang Đăng ký
2. Nhập Họ Tên: `Nguyễn Văn A`
3. Nhập Email: `user01@gmail.com`
4. Nhập Mật khẩu: `Abcd@1234`
5. Nhập Xác nhận mật khẩu: `Abcd@1234`
6. Bấm nút Đăng ký

## Expected result
Đăng ký thành công, hệ thống chuyển hướng tới trang Đăng nhập.
