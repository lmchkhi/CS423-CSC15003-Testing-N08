# TC-FR-01-002: Đăng ký với Họ Tên rỗng

## Requirement ID
FR-01

## Module / Test type / Technique
Register / Functional / Domain Testing

## Preconditions
- User chưa có tài khoản trong hệ thống
- User đang ở trang Đăng ký

## Test data
| Field | Value |
|---|---|
| Họ Tên | _(để trống)_ |
| Email | user02@gmail.com |
| Mật khẩu | Abcd@1234 |
| Xác nhận mật khẩu | Abcd@1234 |

## Test steps
1. Mở trang Đăng ký
2. Để trống trường Họ Tên
3. Nhập Email: `user02@gmail.com`
4. Nhập Mật khẩu: `Abcd@1234`
5. Nhập Xác nhận mật khẩu: `Abcd@1234`
6. Bấm nút Đăng ký

## Expected result
Hệ thống hiển thị thông báo lỗi yêu cầu nhập Họ Tên. Không thực hiện đăng ký.

## Status / Related bugs
Not Run / None
