# TC-FR-01-011: Đăng ký với Mật khẩu thiếu chữ số

## Requirement ID
FR-01

## Module / Test type / Technique
Register / Functional / Domain Testing

## Preconditions
- User chưa có tài khoản trong hệ thống
- User đang ở trang Đăng ký

## Test data
| Field | Value |
|---|---|
| Họ Tên | Nguyễn Văn A |
| Email | user07@gmail.com |
| Mật khẩu | Abcd@efgh |
| Xác nhận mật khẩu | Abcd@efgh |

## Test steps
1. Mở trang Đăng ký
2. Nhập Họ Tên: `Nguyễn Văn A`
3. Nhập Email: `user07@gmail.com`
4. Nhập Mật khẩu: `Abcd@efgh` (không có chữ số)
5. Nhập Xác nhận mật khẩu: `Abcd@efgh`
6. Bấm nút Đăng ký

## Expected result
Hệ thống hiển thị thông báo lỗi mật khẩu phải có ít nhất 1 chữ số. Không thực hiện đăng ký.

## Status / Related bugs
Passed / None
