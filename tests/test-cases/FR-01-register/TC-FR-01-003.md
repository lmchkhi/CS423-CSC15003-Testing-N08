# TC-FR-01-003: Đăng ký với Email rỗng

## Requirement ID
FR-01

## Module / Test type / Technique
Register / Functional / Domain Testing

## Preconditions
- User chưa có tài khoản trong hệ thống
- User đang ở trang Đăng ký

## Test data
| Field | Value |
|---|---|
| Họ Tên | Nguyễn Văn A |
| Email | _(để trống)_ |
| Mật khẩu | Abcd@1234 |
| Xác nhận mật khẩu | Abcd@1234 |

## Test steps
1. Mở trang Đăng ký
2. Nhập Họ Tên: `Nguyễn Văn A`
3. Để trống trường Email
4. Nhập Mật khẩu: `Abcd@1234`
5. Nhập Xác nhận mật khẩu: `Abcd@1234`
6. Bấm nút Đăng ký

## Expected result
Hệ thống hiển thị thông báo lỗi yêu cầu nhập Email. Không thực hiện đăng ký.

## Status / Related bugs
Passed / None
