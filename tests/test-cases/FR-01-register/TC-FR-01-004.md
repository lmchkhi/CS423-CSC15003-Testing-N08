# TC-FR-01-004: Đăng ký với Email sai định dạng (thiếu @)

## Requirement ID
FR-01

## Module / Test type / Technique
Register / Functional / Domain Testing

## Preconditions
- User chưa có tài khoản trong hệ thống
- User đang ở trang Đăng ký

## Test data
| Field | Value |
|---|---|
| Họ Tên | Nguyễn Văn A |
| Email | user01gmail.com |
| Mật khẩu | Abcd@1234 |
| Xác nhận mật khẩu | Abcd@1234 |

## Test steps
1. Mở trang Đăng ký
2. Nhập Họ Tên: `Nguyễn Văn A`
3. Nhập Email: `user01gmail.com`
4. Nhập Mật khẩu: `Abcd@1234`
5. Nhập Xác nhận mật khẩu: `Abcd@1234`
6. Bấm nút Đăng ký

## Expected result
Hệ thống hiển thị thông báo lỗi Email không đúng định dạng. Không thực hiện đăng ký.

Not Run / None
