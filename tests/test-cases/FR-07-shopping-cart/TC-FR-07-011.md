# TC-FR-07-011: Nhãn tổng tiền hiển thị "Tổng cộng"

## Requirement ID
FR-07

## Module / Test type / Technique
Shopping Cart / Functional / Domain Testing

## Preconditions
- Giỏ hàng có ít nhất 1 sản phẩm
- User đang ở trang Giỏ hàng

## Test data
| Field | Value |
|---|---|
| Sản phẩm trong giỏ | iPhone 15 Pro Max |

## Test steps
1. Mở trang Giỏ hàng (đã có sản phẩm)
2. Quan sát nhãn hiển thị tổng tiền ở cuối bảng giỏ hàng
3. Kiểm tra nhãn có đúng là "Tổng cộng" không

## Expected result
Nhãn tổng tiền hiển thị chính xác là **"Tổng cộng"** (không phải "Tổng tạm tính" hay nhãn khác). Giá trị tổng tiền được tính đúng bằng tổng các cột "Thành tiền".
