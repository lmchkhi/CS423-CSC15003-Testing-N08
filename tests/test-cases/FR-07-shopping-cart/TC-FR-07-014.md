# TC-FR-07-014: Thêm nhiều sản phẩm khác nhau — hiển thị nhiều dòng

## Requirement ID
FR-07

## Module / Test type / Technique
Shopping Cart / Functional / Domain Testing

## Preconditions
- Giỏ hàng hiện tại đang trống
- User đang ở trang chủ

## Test data
| Field | Value |
|---|---|
| Sản phẩm 1 | iPhone 15 Pro Max |
| Sản phẩm 2 | Samsung Galaxy S24 Ultra |

## Test steps
1. Mở trang chủ
2. Bấm nút `Thêm vào giỏ` của sản phẩm "iPhone 15 Pro Max"
3. Bấm nút `Thêm vào giỏ` của sản phẩm "Samsung Galaxy S24 Ultra"
4. Mở trang Giỏ hàng
5. Kiểm tra danh sách sản phẩm

## Expected result
Giỏ hàng hiển thị **2 dòng** riêng biệt cho 2 sản phẩm khác nhau, mỗi dòng có đầy đủ thông tin: Sản phẩm, Đơn giá, Số lượng (= 1), Thành tiền, Thao tác. Tổng cộng = tổng Thành tiền của cả 2 sản phẩm.

## Status / Related bugs
Passed / None
