# TC-FR-07-002: Kiểm tra tên cột "Đơn giá" hiển thị đúng

## Requirement ID
FR-07

## Module / Test type / Technique
Shopping Cart / Functional / Domain Testing

## Preconditions
- Giỏ hàng có ít nhất 1 sản phẩm
- User đang ở trang Giỏ hàng

## Test data
| Field | Value |
|---|---|
| Sản phẩm trong giỏ | iPhone 15 Pro Max |

## Test steps
1. Mở trang Giỏ hàng (đã có sản phẩm)
2. Quan sát tiêu đề các cột trong bảng giỏ hàng
3. Kiểm tra cột thứ 2 có tên là "Đơn giá"

## Expected result
Cột thứ 2 trong bảng giỏ hàng hiển thị tiêu đề là **"Đơn giá"** (không phải "Giá" hay tên khác).
