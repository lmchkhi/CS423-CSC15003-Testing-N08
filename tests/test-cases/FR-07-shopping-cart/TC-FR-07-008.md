# TC-FR-07-008: Xác nhận xóa sản phẩm — sản phẩm bị xóa khỏi giỏ

## Requirement ID
FR-07

## Module / Test type / Technique
Shopping Cart / Functional / Domain Testing

## Preconditions
- Giỏ hàng có ít nhất 1 sản phẩm
- User đang ở trang Giỏ hàng

## Test data
| Field | Value |
|---|---|
| Sản phẩm trong giỏ | iPhone 15 Pro Max |
| Hành động trên dialog | Xác nhận xóa |

## Test steps
1. Mở trang Giỏ hàng (đã có sản phẩm)
2. Bấm nút `Xóa` ở cột "Thao tác"
3. Dialog xác nhận xuất hiện
4. Bấm nút xác nhận (ví dụ: "Đồng ý" / "Xóa")

## Expected result
Sản phẩm bị **xóa khỏi giỏ hàng**. Tổng cộng được cập nhật lại. Nếu giỏ hàng trống, hiển thị giao diện giỏ hàng trống.

## Status / Related bugs
Not Run / None
