# TC-FR-07-013: Kiểm tra cột Thành tiền = Đơn giá × Số lượng

## Requirement ID
FR-07

## Module / Test type / Technique
Shopping Cart / Functional / Domain Testing

## Preconditions
- Giỏ hàng có 1 sản phẩm với số lượng > 1
- User đang ở trang Giỏ hàng

## Test data
| Field | Value |
|---|---|
| Sản phẩm | iPhone 15 Pro Max |
| Đơn giá | 30,000,000 đ |
| Số lượng | 3 |
| Thành tiền (mong đợi) | 90,000,000 đ |

## Test steps
1. Thêm sản phẩm "iPhone 15 Pro Max" vào giỏ hàng
2. Tăng số lượng lên 3 (bằng nút + hoặc thêm nhiều lần)
3. Mở trang Giỏ hàng
4. Kiểm tra giá trị cột "Thành tiền"

## Expected result
Cột "Thành tiền" hiển thị giá trị = **Đơn giá × Số lượng** = 30,000,000 × 3 = **90,000,000 đ**. Tổng cộng cũng hiển thị đúng.
