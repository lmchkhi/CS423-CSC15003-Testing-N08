# TC-FR-07-005: Bấm nút - để giảm số lượng sản phẩm

## Requirement ID
FR-07

## Module / Test type / Technique
Shopping Cart / Functional / Domain Testing

## Preconditions
- Giỏ hàng có 1 sản phẩm với số lượng = 2
- User đang ở trang Giỏ hàng

## Test data
| Field | Value |
|---|---|
| Sản phẩm trong giỏ | iPhone 15 Pro Max |
| Số lượng trước | 2 |
| Hành động | Bấm nút - |
| Số lượng sau (mong đợi) | 1 |

## Test steps
1. Mở trang Giỏ hàng (sản phẩm có số lượng = 2)
2. Bấm nút `-` bên cạnh số lượng sản phẩm
3. Quan sát số lượng và thành tiền sau khi bấm

## Expected result
Số lượng sản phẩm giảm từ 2 xuống **1**. Cột "Thành tiền" cập nhật tương ứng (= Đơn giá × 1). Tổng cộng cập nhật đúng.
