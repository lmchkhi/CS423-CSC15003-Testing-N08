# TC-FR-07-017: BVA — Số lượng = 2 (OFF⁺ — min+1), hợp lệ

## Requirement ID
FR-07

## Module / Test type / Technique
Shopping Cart / Functional / Boundary Value Analysis

## Preconditions
- Giỏ hàng có 1 sản phẩm với số lượng = 1
- User đang ở trang Giỏ hàng

## Test data
| Field | Value |
|---|---|
| Sản phẩm | iPhone 15 Pro Max |
| Số lượng trước | 1 |
| Hành động | Bấm nút + 1 lần |
| Số lượng sau (mong đợi) | 2 (biên min + 1) |

## Test steps
1. Mở trang Giỏ hàng (sản phẩm có số lượng = 1)
2. Bấm nút `+` bên cạnh số lượng sản phẩm
3. Kiểm tra số lượng, thành tiền và tổng cộng

## Expected result
Số lượng tăng lên **2**. Thành tiền = Đơn giá × 2. Tổng cộng cập nhật đúng. Hoạt động bình thường.
