# TC-FR-07-016: BVA — Số lượng = 0 (OFF⁻ — min-1), không hợp lệ

## Requirement ID
FR-07

## Module / Test type / Technique
Shopping Cart / Functional / Boundary Value Analysis

## Preconditions
- Giỏ hàng có 1 sản phẩm với số lượng = 1
- User đang ở trang Giỏ hàng

## Test data
| Field | Value |
|---|---|
| Sản phẩm | iPhone 15 Pro Max |
| Số lượng cố gắng đặt | 0 (biên min - 1) |

## Test steps
1. Mở trang Giỏ hàng (sản phẩm có số lượng = 1)
2. Thử giảm số lượng xuống 0 bằng cách bấm nút `-`
3. Quan sát kết quả — số lượng có xuống 0 không

## Expected result
Hệ thống **không cho phép** số lượng = 0. Nút `-` bị vô hiệu hóa khi số lượng = 1, hoặc hiển thị cảnh báo/dialog xác nhận xóa sản phẩm.
