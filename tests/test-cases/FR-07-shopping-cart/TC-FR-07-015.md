# TC-FR-07-015: BVA — Số lượng = 1 (ON — min), bấm nút - không giảm được nữa

## Requirement ID
FR-07

## Module / Test type / Technique
Shopping Cart / Functional / Boundary Value Analysis

## Preconditions
- Giỏ hàng có 1 sản phẩm với số lượng = 1
- User đang ở trang Giỏ hàng

## Test data
| Field | Value |
|---|---|
| Sản phẩm | iPhone 15 Pro Max |
| Số lượng hiện tại | 1 (biên min) |
| Hành động | Bấm nút - |

## Test steps
1. Mở trang Giỏ hàng (sản phẩm có số lượng = 1)
2. Bấm nút `-` bên cạnh số lượng sản phẩm
3. Quan sát kết quả

## Expected result
Số lượng **không giảm xuống dưới 1** (hoặc hệ thống hiển thị dialog xác nhận xóa). Nút `-` bị vô hiệu hóa khi số lượng = 1, hoặc sản phẩm bị xóa với dialog xác nhận.

Not Run / None
