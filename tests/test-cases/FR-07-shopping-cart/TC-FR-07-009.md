# TC-FR-07-009: Hủy xóa sản phẩm — sản phẩm vẫn còn trong giỏ

## Requirement ID
FR-07

## Module / Test type / Technique
Shopping Cart / Functional / Domain Testing

## Preconditions
- Giỏ hàng có ít nhất 1 sản phẩm
- User đang ở trang Giỏ hàng

## Test data
| Field | Value |
|---|---|
| Sản phẩm trong giỏ | iPhone 15 Pro Max |
| Hành động trên dialog | Hủy |

## Test steps
1. Mở trang Giỏ hàng (đã có sản phẩm)
2. Bấm nút `Xóa` ở cột "Thao tác"
3. Dialog xác nhận xuất hiện
4. Bấm nút hủy (ví dụ: "Hủy" / "Không")

## Expected result
Sản phẩm **vẫn còn trong giỏ hàng** với số lượng và thành tiền không thay đổi. Dialog đóng lại.
