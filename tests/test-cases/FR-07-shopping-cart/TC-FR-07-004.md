# TC-FR-07-004: Bấm nút + để tăng số lượng sản phẩm

## Requirement ID
FR-07

## Module / Test type / Technique
Shopping Cart / Functional / Domain Testing

## Preconditions
- Giỏ hàng có 1 sản phẩm với số lượng = 1
- User đang ở trang Giỏ hàng

## Test data
| Field | Value |
|---|---|
| Sản phẩm trong giỏ | iPhone 15 Pro Max |
| Số lượng trước | 1 |
| Hành động | Bấm nút + |
| Số lượng sau (mong đợi) | 2 |

## Test steps
1. Mở trang Giỏ hàng (sản phẩm có số lượng = 1)
2. Bấm nút `+` bên cạnh số lượng sản phẩm
3. Quan sát số lượng và thành tiền sau khi bấm

## Expected result
Số lượng sản phẩm tăng từ 1 lên **2**. Cột "Thành tiền" cập nhật tương ứng (= Đơn giá × 2). Tổng cộng cập nhật đúng.
