# TC-FR-07-001: Hiển thị giỏ hàng với 1 sản phẩm — kiểm tra đầy đủ các cột

## Requirement ID
FR-07

## Module / Test type / Technique
Shopping Cart / Functional / Domain Testing

## Preconditions
- User đang ở trang chủ (Danh sách sản phẩm)
- Giỏ hàng hiện tại đang trống

## Test data
| Field | Value |
|---|---|
| Sản phẩm thêm vào | iPhone 15 Pro Max |
| Số lượng | 1 |

## Test steps
1. Mở trang chủ
2. Bấm nút `Thêm vào giỏ` của sản phẩm "iPhone 15 Pro Max"
3. Bấm vào liên kết `Giỏ hàng` trên thanh điều hướng

## Expected result
Giỏ hàng hiển thị danh sách sản phẩm với đầy đủ 5 cột theo thứ tự: **Sản phẩm**, **Đơn giá**, **Số lượng** (có nút +/-), **Thành tiền**, **Thao tác**. Sản phẩm "iPhone 15 Pro Max" hiển thị đúng thông tin.
