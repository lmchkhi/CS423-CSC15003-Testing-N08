# TC-FR-07-012: Giỏ hàng trống — hiển thị hình minh họa và thông báo

## Requirement ID
FR-07

## Module / Test type / Technique
Shopping Cart / Functional / Domain Testing

## Preconditions
- Giỏ hàng không có sản phẩm nào
- User đang ở trang Giỏ hàng

## Test data
| Field | Value |
|---|---|
| Trạng thái giỏ hàng | Trống (0 sản phẩm) |

## Test steps
1. Đảm bảo giỏ hàng trống (xóa hết sản phẩm nếu có)
2. Mở trang Giỏ hàng
3. Quan sát giao diện giỏ hàng trống

## Expected result
Trang giỏ hàng trống hiển thị:
1. **Hình minh họa** (ví dụ: hình giỏ hàng trống, icon cart rỗng)
2. **Thông báo rõ ràng** (ví dụ: "Giỏ hàng của bạn đang trống")
3. Liên kết/nút **"Tiếp tục mua sắm"** để quay về trang chủ
