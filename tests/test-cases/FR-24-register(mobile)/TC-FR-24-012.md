# TC-FR-24-012: Đăng ký với Mật khẩu thiếu ký tự đặc biệt

## Requirement ID
FR-24

## Module / Test type / Technique
Register / Functional / Domain Testing

## Preconditions
- User chưa có tài khoản trong hệ thống
- User đang ở màn hình Đăng ký

## Test data
| Field | Value |
|---|---|
| Họ Tên | Nguyễn Văn A |
| Email | user08@gmail.com |
| Mật khẩu | Abcd12345 |
| Xác nhận mật khẩu | Abcd12345 |

## Test steps
1. Mở màn hình Đăng ký
2. Nhập Họ Tên: `Nguyễn Văn A`
3. Nhập Email: `user08@gmail.com`
4. Nhập Mật khẩu: `Abcd12345` (không có ký tự đặc biệt)
5. Nhập Xác nhận mật khẩu: `Abcd12345`
6. Bấm nút Đăng ký

## Expected result
Hệ thống hiển thị thông báo lỗi mật khẩu phải có ít nhất 1 ký tự đặc biệt (@, $, !, %, *, ?, &). Không thực hiện đăng ký.
