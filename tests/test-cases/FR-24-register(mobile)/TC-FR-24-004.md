# TC-FR-24-004: Đăng ký với Email sai định dạng (thiếu @)

## Requirement ID
FR-24

## Module / Test type / Technique
Register / Functional / Domain Testing

## Preconditions
- User chưa có tài khoản trong hệ thống
- User đang ở màn hình Đăng ký

## Test data
| Field | Value |
|---|---|
| Họ Tên | Nguyễn Văn A |
| Email | user01gmail.com |
| Mật khẩu | Abcd@1234 |
| Xác nhận mật khẩu | Abcd@1234 |

## Test steps
1. Mở màn hình Đăng ký
2. Nhập Họ Tên: `Nguyễn Văn A`
3. Nhập Email: `user01gmail.com`
4. Nhập Mật khẩu: `Abcd@1234`
5. Nhập Xác nhận mật khẩu: `Abcd@1234`
6. Bấm nút Đăng ký

## Expected result
Hệ thống hiển thị thông báo lỗi email không hợp lệ. Không thực hiện đăng ký.
