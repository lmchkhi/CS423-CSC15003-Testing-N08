# TC-FR-24-007: Đăng ký với Mật khẩu rỗng

## Requirement ID
FR-24

## Module / Test type / Technique
Register / Functional / Domain Testing

## Preconditions
- User chưa có tài khoản trong hệ thống
- User đang ở màn hình Đăng ký

## Test data
| Field | Value |
|---|---|
| Họ Tên | Nguyễn Văn A |
| Email | user03@gmail.com |
| Mật khẩu | _(để trống)_ |
| Xác nhận mật khẩu | _(để trống)_ |

## Test steps
1. Mở màn hình Đăng ký
2. Nhập Họ Tên: `Nguyễn Văn A`
3. Nhập Email: `user03@gmail.com`
4. Để trống trường Mật khẩu
5. Để trống trường Xác nhận mật khẩu
6. Bấm nút Đăng ký

## Expected result
Hệ thống hiển thị thông báo lỗi yêu cầu nhập Mật khẩu. Không thực hiện đăng ký.
