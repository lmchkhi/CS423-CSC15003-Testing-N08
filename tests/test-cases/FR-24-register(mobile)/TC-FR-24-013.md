# TC-FR-24-013: Đăng ký với Xác nhận mật khẩu không khớp

## Requirement ID
FR-24

## Module / Test type / Technique
Register / Functional / Domain Testing

## Preconditions
- User chưa có tài khoản trong hệ thống
- User đang ở màn hình Đăng ký

## Test data
| Field | Value |
|---|---|
| Họ Tên | Nguyễn Văn A |
| Email | user09@gmail.com |
| Mật khẩu | Abcd@1234 |
| Xác nhận mật khẩu | Abcd@5678 |

## Test steps
1. Mở màn hình Đăng ký
2. Nhập Họ Tên: `Nguyễn Văn A`
3. Nhập Email: `user09@gmail.com`
4. Nhập Mật khẩu: `Abcd@1234`
5. Nhập Xác nhận mật khẩu: `Abcd@5678` (không khớp với Mật khẩu)
6. Bấm nút Đăng ký

## Expected result
Hệ thống hiển thị thông báo lỗi xác nhận mật khẩu không khớp. Không thực hiện đăng ký.
