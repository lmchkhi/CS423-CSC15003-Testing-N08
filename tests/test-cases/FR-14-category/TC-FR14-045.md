# TC-FR14-045: Tên category trùng được chấp nhận

## Mã yêu cầu
FR-14, SEC-02, SEC-03, SEC-05

## Module / Loại kiểm thử / Kỹ thuật
Category CRUD API / Functional / Bảo mật / Kiểm thử miền API / CRUD / Bảo mật

## Phân tích miền

### Biến đầu vào & miền giá trị

| Biến | Kiểu | Miền giá trị / Ràng buộc |
|---|---|---|
| HTTP operation | GET / POST / PUT / DELETE | Bao phủ danh sách category, tạo, cập nhật, xóa, lifecycle và flow resource không tồn tại. |
| name | String / JSON field | Tên category là bắt buộc; bao phủ hợp lệ, rỗng, thiếu field, khoảng trắng, quá dài, Unicode, ký tự đặc biệt, số, trùng, SQL/XSS và giá trị biên. |
| auth role | Trạng thái JWT | Bao phủ không có token, token không hợp lệ, token user thường và token admin. |
| category id | Path parameter | Bao phủ id tồn tại, id không tồn tại và id được tạo trong lifecycle. |

### Ma trận miền

| TC | Dữ liệu / Hành động | Tiền điều kiện | Kết quả mong đợi | Oracle kiểm thử |
|---|---|---|---|---|
| TC-FR14-045 | Tạo category `Điện thoại` hai lần bằng admin token. | Category `Điện thoại` đã tồn tại. | Phải trả 400 Bad Request hoặc 409 Conflict. | Quan sát được 200 OK cả hai lần; cho phép tên category trùng. |

## Tiền điều kiện
- Backend API đang chạy tại `http://localhost:3000`.
- Request có header `X-Student-Id: 23127300`.
- Token user/admin và category id cần thiết được chuẩn bị trước các test case tương ứng.

## Dữ liệu kiểm thử

| Trường | Giá trị |
|---|---|
| Endpoint | `POST /api/categories` |
| Token | JWT của admin |
| Body | `{"name":"Điện thoại"}` hai lần |

## Các bước kiểm thử
1. Chuẩn bị xác thực và trạng thái category cần thiết.
2. Gửi API request theo dữ liệu kiểm thử đã mô tả.
3. Ghi nhận HTTP status và response body.
4. Kiểm tra kết quả CRUD, schema, hành vi kiểm soát truy cập hoặc oracle toàn vẹn dữ liệu.

## Kết quả mong đợi
Phải trả 400 Bad Request hoặc 409 Conflict.

Oracle: Quan sát được 200 OK cả hai lần; cho phép tên category trùng.
