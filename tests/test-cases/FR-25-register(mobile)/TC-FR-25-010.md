# TC-FR-25-010: Đăng ký với Mật khẩu thiếu chữ thường

## Requirement ID
FR-25

## Module / Test type / Technique
Register / Functional / Domain Testing

## Preconditions
- User chưa có tài khoản trong hệ thống
- User đang ở màn hình Đăng ký

## Test data
| Field | Value |
|---|---|
| Họ Tên | Nguyễn Văn A |
| Email | user06@gmail.com |
| Mật khẩu | ABCD@1234 |
| Xác nhận mật khẩu | ABCD@1234 |

## Test steps
1. Mở màn hình Đăng ký
2. Nhập Họ Tên: `Nguyễn Văn A`
3. Nhập Email: `user06@gmail.com`
4. Nhập Mật khẩu: `ABCD@1234` (không có chữ thường)
5. Nhập Xác nhận mật khẩu: `ABCD@1234`
6. Bấm nút Đăng ký

## Expected result
Hệ thống hiển thị thông báo lỗi mật khẩu phải có ít nhất 1 chữ thường. Không thực hiện đăng ký.

## Status / Related bugs
