# TC-FR-25-006: Đăng ký với Email đã tồn tại

## Requirement ID
FR-25

## Module / Test type / Technique
Register / Functional / Domain Testing

## Preconditions
- Email `existing@gmail.com` đã được đăng ký trong hệ thống
- User đang ở màn hình Đăng ký

## Test data
| Field | Value |
|---|---|
| Họ Tên | Nguyễn Văn A |
| Email | existing@gmail.com |
| Mật khẩu | Abcd@1234 |
| Xác nhận mật khẩu | Abcd@1234 |

## Test steps
1. Mở màn hình Đăng ký
2. Nhập Họ Tên: `Nguyễn Văn A`
3. Nhập Email: `existing@gmail.com`
4. Nhập Mật khẩu: `Abcd@1234`
5. Nhập Xác nhận mật khẩu: `Abcd@1234`
6. Bấm nút Đăng ký

## Expected result
Hệ thống hiển thị thông báo lỗi email đã tồn tại. Không thực hiện đăng ký.
