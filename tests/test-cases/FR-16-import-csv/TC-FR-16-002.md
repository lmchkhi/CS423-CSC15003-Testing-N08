# TC-FR-16-002: Upload file không phải .csv

## Requirement ID
FR-16

## Module / Test type / Technique
ImportCSV / Functional / Domain Testing

## Preconditions
- Admin đã đăng nhập vào hệ thống
- Admin đang ở trang Import sản phẩm từ CSV

## Test data
| Field | Value |
|---|---|
| File tải lên | `products.txt` (đuôi `.txt`) |
| Nội dung file | Dữ liệu CSV hợp lệ nhưng đuôi file sai |

## Test steps
1. Mở trang Import sản phẩm từ CSV
2. Chọn file `products.txt` để tải lên
3. Bấm nút Import

## Expected result
Hệ thống từ chối file, hiển thị thông báo lỗi: file phải có đuôi `.csv`. Không thực hiện import.
