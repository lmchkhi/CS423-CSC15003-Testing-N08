# TC-FR-16-011: File CSV có 1 dòng lỗi — kiểm tra rollback toàn bộ

## Requirement ID
FR-16

## Module / Test type / Technique
ImportCSV / Functional / Domain Testing

## Preconditions
- Admin đã đăng nhập vào hệ thống
- Admin đang ở trang Import sản phẩm từ CSV
- Hệ thống chưa có sản phẩm nào trong cơ sở dữ liệu (hoặc ghi nhận số lượng trước khi import)

## Test data
| Field | Value |
|---|---|
| File CSV | `products_rollback.csv` (đuôi `.csv`) |
| Header | `name,price,description,imageUrl,category_id` |
| Dòng 2 | `Laptop Dell,15000000,Laptop văn phòng,https://img.com/dell.jpg,1` (hợp lệ) |
| Dòng 3 | `,25000000,Điện thoại cao cấp,https://img.com/iphone.jpg,2` (name rỗng — lỗi) |
| Dòng 4 | `Tai nghe Sony,1500000,Tai nghe chống ồn,https://img.com/sony.jpg,3` (hợp lệ) |

## Test steps
1. Mở trang Import sản phẩm từ CSV
2. Ghi nhận số lượng sản phẩm hiện có trong hệ thống
3. Chọn file `products_rollback.csv` để tải lên
4. Bấm nút Import
5. Kiểm tra số lượng sản phẩm trong hệ thống sau khi import

## Expected result
Import thất bại. Toàn bộ giao dịch bị rollback (all-or-nothing). Kiểm tra: không có sản phẩm mới nào được thêm (Laptop Dell và Tai nghe Sony cũng không được lưu). Số lượng sản phẩm giữ nguyên như trước khi import.
