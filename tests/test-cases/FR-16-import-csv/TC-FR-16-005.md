# TC-FR-16-005: File CSV có dòng dữ liệu với name rỗng

## Requirement ID
FR-16

## Module / Test type / Technique
ImportCSV / Functional / Domain Testing

## Preconditions
- Admin đã đăng nhập vào hệ thống
- Admin đang ở trang Import sản phẩm từ CSV

## Test data
| Field | Value |
|---|---|
| File CSV | `products_empty_name.csv` (đuôi `.csv`) |
| Header | `name,price,description,imageUrl,category_id` |
| Dòng 2 | `Laptop Dell,15000000,Laptop văn phòng,https://img.com/dell.jpg,1` |
| Dòng 3 | `,25000000,Điện thoại cao cấp,https://img.com/iphone.jpg,2` (name rỗng) |
| Dòng 4 | `Tai nghe Sony,1500000,Tai nghe chống ồn,https://img.com/sony.jpg,3` |

## Test steps
1. Mở trang Import sản phẩm từ CSV
2. Chọn file `products_empty_name.csv` để tải lên
3. Bấm nút Import

## Expected result
Import thất bại. Toàn bộ giao dịch bị rollback — không có sản phẩm nào được lưu. Báo cáo hiển thị: 0 dòng thành công, 1 dòng lỗi (dòng 3: name không được rỗng).
