# TC-FR-16-001: Import thành công với file CSV hợp lệ

## Requirement ID
FR-16

## Module / Test type / Technique
ImportCSV / Functional / Domain Testing

## Preconditions
- Admin đã đăng nhập vào hệ thống
- Admin đang ở trang Import sản phẩm từ CSV

## Test data
| Field | Value |
|---|---|
| File CSV | `products_valid.csv` (đuôi `.csv`) |
| Header | `name,price,description,imageUrl,category_id` |
| Dòng 2 | `Laptop Dell,15000000,Laptop văn phòng,https://img.com/dell.jpg,1` |
| Dòng 3 | `iPhone 15,25000000,Điện thoại cao cấp,https://img.com/iphone.jpg,2` |

## Test steps
1. Mở trang Import sản phẩm từ CSV
2. Chọn file `products_valid.csv` để tải lên
3. Bấm nút Import

## Expected result
Import thành công. Tất cả 3 sản phẩm được lưu vào hệ thống. Báo cáo hiển thị: 3 dòng thành công, 0 dòng lỗi.
