# TC-FR-16-010: File CSV có trường chứa dấu phẩy bọc trong nháy kép (RFC 4180)

## Requirement ID
FR-16

## Module / Test type / Technique
ImportCSV / Functional / Domain Testing

## Preconditions
- Admin đã đăng nhập vào hệ thống
- Admin đang ở trang Import sản phẩm từ CSV

## Test data
| Field | Value |
|---|---|
| File CSV | `products_comma_in_field.csv` (đuôi `.csv`) |
| Header | `name,price,description,imageUrl,category_id` |
| Dòng 2 | `Laptop Dell,15000000,"Màn hình 15.6 inch, Full HD, RAM 16GB",https://img.com/dell.jpg,1` |
| Dòng 3 | `iPhone 15,25000000,"Camera 48MP, chip A16",https://img.com/iphone.jpg,2` |

## Test steps
1. Mở trang Import sản phẩm từ CSV
2. Chọn file `products_comma_in_field.csv` để tải lên
3. Bấm nút Import

## Expected result
Import thành công. Hệ thống parse đúng trường `description` chứa dấu phẩy (không bị tách cột sai). 2 sản phẩm được lưu với mô tả đầy đủ. Báo cáo hiển thị: 2 dòng thành công, 0 dòng lỗi.
