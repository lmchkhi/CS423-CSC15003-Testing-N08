# TC-FR-16-004: File CSV có header sai (thiếu cột)

## Requirement ID
FR-16

## Module / Test type / Technique
ImportCSV / Functional / Domain Testing

## Preconditions
- Admin đã đăng nhập vào hệ thống
- Admin đang ở trang Import sản phẩm từ CSV

## Test data
| Field | Value |
|---|---|
| File CSV | `products_bad_header.csv` (đuôi `.csv`) |
| Header | `name,price,description` (thiếu cột `imageUrl` và `category_id`) |
| Dòng 2 | `Laptop Dell,15000000,Laptop văn phòng` |

## Test steps
1. Mở trang Import sản phẩm từ CSV
2. Chọn file `products_bad_header.csv` để tải lên
3. Bấm nút Import

## Expected result
Hệ thống từ chối file, hiển thị thông báo lỗi: header không đúng định dạng yêu cầu (`name,price,description,imageUrl,category_id`). Không thực hiện import.
