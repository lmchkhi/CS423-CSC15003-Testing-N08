# TC-FR-16-012: Kiểm tra báo cáo kết quả hiển thị số dòng thành công/lỗi và lý do

## Requirement ID
FR-16

## Module / Test type / Technique
ImportCSV / Functional / Domain Testing

## Preconditions
- Admin đã đăng nhập vào hệ thống
- Admin đang ở trang Import sản phẩm từ CSV

## Test data
| Field | Value |
|---|---|
| File CSV | `products_mixed.csv` (đuôi `.csv`) |
| Header | `name,price,description,imageUrl,category_id` |
| Dòng 2 | `Laptop Dell,15000000,Laptop văn phòng,https://img.com/dell.jpg,1` (hợp lệ) |
| Dòng 3 | `,25000000,Điện thoại,https://img.com/iphone.jpg,2` (name rỗng) |
| Dòng 4 | `Tai nghe Sony,-1000,Tai nghe,https://img.com/sony.jpg,3` (price âm) |

## Test steps
1. Mở trang Import sản phẩm từ CSV
2. Chọn file `products_mixed.csv` để tải lên
3. Bấm nút Import
4. Kiểm tra nội dung báo cáo kết quả hiển thị trên giao diện

## Expected result
Hệ thống hiển thị báo cáo rõ ràng gồm: số dòng thành công (1), số dòng lỗi (2), và lý do cụ thể cho mỗi dòng lỗi (dòng 3: name không được rỗng; dòng 4: price phải là số dương). Toàn bộ import bị rollback do có lỗi.
