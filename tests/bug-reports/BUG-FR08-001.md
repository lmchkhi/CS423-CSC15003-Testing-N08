# [BUG][Checkout] Client có thể sửa và quyết định tổng tiền đơn hàng

## Found by Test Case

- TC-CHECKOUT-004
- TC-CHECKOUT-005
- TC-CHECKOUT-010

## Requirement liên quan

FR-08

## Severity / Priority

Critical / P0

## Environment

- Application: EShop Web + Backend API
- URL: `http://localhost:5173/checkout`
- Backend: `http://localhost:3000`
- OS: macOS 26.5.2
- Browser: Chrome 149.0.7827.201
- Node.js: v24.18.0
- Build/commit: `969e156`
- Execution date: 2026-07-06 (Asia/Ho_Chi_Minh)

## Steps to reproduce

1. Đăng nhập bằng `test@eshop.com`.
2. Thêm iPhone 15 Pro Max, số lượng 1, vào giỏ.
3. Mở Checkout và quan sát tổng đúng là 30.000.000 ₫.
4. Focus trường `Tổng tiền thanh toán (VND)` và thay giá trị bằng `1`.
5. Gửi Checkout; hoặc gửi trực tiếp payload có `total_amount: 1`.

## Expected result

- Tổng tiền chỉ là dữ liệu do hệ thống tính, không thể sửa trên giao diện.
- Backend bỏ qua mọi `total_amount` do client gửi và tự tính lại từ sản phẩm trong giỏ.
- Đơn hàng phải có tổng 30.000.000 ₫.

## Actual result

- Trang Checkout hiển thị tổng tiền dưới dạng `<input type="number">` có thể chỉnh sửa.
- Request Checkout gửi chính giá trị đã sửa trong `total_amount`.
- Backend chèn trực tiếp `req.body.total_amount` vào bảng `orders`, không tự tính lại từ giỏ hàng.

## Evidence

- Browser DOM tại Checkout ghi nhận input tổng tiền: `type="number" value="30000000"` và không có thuộc tính `disabled`/`readonly`.
- Màn hình Checkout hiển thị iPhone 15 Pro Max × 1 với tổng 30.000.000 ₫.
- Frontend tạo `editableTotal` và gửi nó trong payload tại `frontend-web/src/pages/Checkout.jsx`.
- Backend đọc `total_amount` từ body và ghi thẳng vào đơn tại `backend/server.js` (endpoint `POST /api/checkout`).
