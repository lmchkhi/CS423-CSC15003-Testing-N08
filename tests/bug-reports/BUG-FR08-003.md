# [BUG][Checkout] Backend tạo đơn khi giỏ hàng trống hoặc gửi lại Checkout

## Found by Test Case

- TC-CHECKOUT-009
- TC-CHECKOUT-011

## Requirement liên quan

FR-08

## Severity / Priority

Critical / P0

## Environment

- Application: EShop Web + Backend API
- URL: `http://localhost:5173/checkout`
- Backend: `http://localhost:3000`
- OS: macOS 26.5.2
- Browser: Chrome 149.0.7827.201
- Node.js: v24.18.0
- Build/commit: `969e156`
- Execution date: 2026-07-06 (Asia/Ho_Chi_Minh)

## Steps to reproduce

1. Đăng nhập bằng `test@eshop.com` với giỏ hàng trống.
2. Mở trực tiếp `http://localhost:5173/checkout`.
3. Quan sát danh sách sản phẩm trống và tổng thanh toán 0 ₫.
4. Bấm `Xác Nhận Thanh Toán`.
5. Lặp lại request Checkout mà không thêm sản phẩm.

## Expected result

Hệ thống từ chối cả hai request, không tạo đơn hàng và hiển thị lỗi “giỏ hàng trống”.

## Actual result

- Trang Checkout không chặn giỏ trống và vẫn hiển thị nút xác nhận.
- Backend không kiểm tra `items`, không đọc giỏ server-side và không kiểm tra tổng số lượng sản phẩm.
- Mỗi request có JWT hợp lệ đều có thể tạo thêm một đơn, kể cả khi `items` rỗng hoặc bị bỏ qua hoàn toàn.

## Evidence

- Component Checkout render form và nút submit độc lập với `cart.length` tại `frontend-web/src/pages/Checkout.jsx`.
- Endpoint `POST /api/checkout` chỉ yêu cầu token, sau đó chèn đơn từ `total_amount`; không có validation giỏ hàng tại `backend/server.js`.
