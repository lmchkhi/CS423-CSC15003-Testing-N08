# Test Runs

Thư mục này dùng để ghi nhận kết quả execute test case theo sprint, release hoặc đợt regression.

Hiện tại bộ FR-10 mới ở trạng thái thiết kế, vì vậy từng test case đang có status `Not Run`. Khi nhóm chạy test, tạo file test run mới trong thư mục này và liên kết kết quả về các mã test case tương ứng như `TC-ORDER-STT-001`, `TC-ORDER-STT-002`.
