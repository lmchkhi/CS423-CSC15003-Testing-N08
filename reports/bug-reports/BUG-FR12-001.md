# BUG-FR12-001: User thường có thể xóa user qua API Admin

## Found by Test Case
TC-FR12-DT-004

## Requirement liên quan
FR-12

## Severity / Priority
Critical / P1

## Environment
**Browser**: N/A - API test bằng curl  
**OS**: Ubuntu/Linux local environment  
**URL**: http://localhost:3000

## Steps to reproduce
1. Tạo user tạm:
   `POST /api/register`
   body:
   `{"name":"FR12 Temp User","email":"fr12-temp-user@example.com","password":"Temp123!"}`
2. Ghi lại id user tạm được tạo. Lần reproduce này user tạm có `id = 3`.
3. Đăng nhập bằng user thường:
   `POST /api/login`
   body:
   `{"email":"test@eshop.com","password":"Test1234!"}`
4. Lấy JWT của user thường từ response login.
5. Gửi request:
   `DELETE /api/admin/users/3`
   với header:
   `Authorization: Bearer <valid-user-token>`

## Expected result
API phải từ chối request vì token hợp lệ nhưng không có `role = 'admin'`. User tạm không bị xóa.

## Actual result
API trả về thành công và xóa user:

```http
HTTP/1.1 200 OK
```

```json
{"message":"User deleted"}
```

## Evidence
Curl response khi gọi `DELETE /api/admin/users/3` bằng JWT của user thường:

```http
HTTP/1.1 200 OK
Content-Type: application/json; charset=utf-8

{"message":"User deleted"}
```
