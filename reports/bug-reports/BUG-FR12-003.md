# BUG-FR12-003: User thường có thể gọi API Admin để xóa coupon

## Found by Test Case
TC-FR12-DT-008

## Requirement liên quan
FR-12

## Severity / Priority
Major / P1

## Environment
**Browser**: N/A - API test bằng curl  
**OS**: Ubuntu/Linux local environment  
**URL**: http://localhost:3000

## Steps to reproduce
1. Tạo coupon tạm bằng admin:
   `POST /api/admin/coupons`
   body:
   `{"code":"FR12DT008","type":"fixed","discount_value":10000,"min_order_amount":0,"expired_at":"2099-12-31","max_uses_per_user":1}`
2. Ghi lại id coupon tạm. Lần reproduce này coupon tạm có `id = 5`.
3. Đăng nhập bằng user thường:
   `POST /api/login`
   body:
   `{"email":"test@eshop.com","password":"Test1234!"}`
4. Lấy JWT của user thường từ response login.
5. Gửi request:
   `DELETE /api/admin/coupons/5`
   với header:
   `Authorization: Bearer <valid-user-token>`

## Expected result
API phải từ chối request vì token hợp lệ nhưng không có `role = 'admin'`. Coupon tạm không được xóa.

## Actual result
API Admin chấp nhận JWT của user thường và trả về thành công:

```http
HTTP/1.1 200 OK
```

```json
{"message":"Coupon deleted"}
```

## Evidence
Curl response khi gọi `DELETE /api/admin/coupons/5` bằng JWT của user thường:

```http
HTTP/1.1 200 OK
Content-Type: application/json; charset=utf-8

{"message":"Coupon deleted"}
```

Sau khi ghi nhận bằng chứng, dữ liệu tạm không còn trong danh sách coupon.
