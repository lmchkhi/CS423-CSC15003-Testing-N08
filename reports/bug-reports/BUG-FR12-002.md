# BUG-FR12-002: API tạo sản phẩm cho phép request không có token

## Found by Test Case
TC-FR12-DT-006

## Requirement liên quan
FR-12

## Severity / Priority
Critical / P1

## Environment
**Browser**: N/A - API test bằng curl  
**OS**: Ubuntu/Linux local environment  
**URL**: http://localhost:3000

## Steps to reproduce
1. Gửi request không có header `Authorization`:
   `POST /api/products`
2. Body:
   `{"name":"FR12 No Token Product 20260629","price":100000,"description":"access control test","imageUrl":"","category_id":1}`
3. Quan sát response.
4. Gọi `GET /api/products?search=FR12%20No%20Token%20Product%2020260629` để kiểm tra sản phẩm có được tạo hay không.

## Expected result
API phải từ chối request vì thiếu JWT hợp lệ. Sản phẩm mới không được tạo.

## Actual result
API trả về thành công và tạo sản phẩm:

```http
HTTP/1.1 200 OK
```

```json
{"message":"Product created","id":6}
```

## Evidence
Response tạo sản phẩm:

```http
HTTP/1.1 200 OK
Content-Type: application/json; charset=utf-8

{"message":"Product created","id":6}
```

Response kiểm tra sau đó cho thấy sản phẩm xuất hiện trong danh sách. Sau khi ghi nhận bằng chứng, dữ liệu tạm đã được dọn bằng tài khoản admin.
