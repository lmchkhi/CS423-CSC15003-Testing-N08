# BUG-FR12-004: User thường có thể cập nhật sản phẩm qua API product

## Found by Test Case
TC-FR12-PW-001

## Requirement liên quan
FR-12

## Severity / Priority
Critical / P1

## Environment
**Browser**: N/A - API test bằng curl  
**OS**: Ubuntu/Linux local environment  
**URL**: http://localhost:3000

## Steps to reproduce
1. Tạo product tạm bằng admin:
   `POST /api/products`
   body:
   `{"name":"FR12 PW User Product Original 20260629","price":111000,"description":"pairwise temp","imageUrl":"","category_id":1}`
2. Ghi lại id product tạm. Lần reproduce này product tạm có `id = 7`.
3. Đăng nhập bằng user thường:
   `POST /api/login`
   body:
   `{"email":"test@eshop.com","password":"Test1234!"}`
4. Lấy JWT của user thường từ response login.
5. Gửi request:
   `PUT /api/products/7`
   với header:
   `Authorization: Bearer <valid-user-token>`
   và body:
   `{"name":"FR12 PW User Product Updated 20260629","price":120000,"description":"pairwise","imageUrl":"","category_id":1}`

## Expected result
API phải từ chối request vì token hợp lệ nhưng không có `role = 'admin'`. Product tạm không bị cập nhật.

## Actual result
API trả về thành công và cập nhật product:

```http
HTTP/1.1 200 OK
```

```json
{"message":"Product updated"}
```

## Evidence
Sau request, `GET /api/products?search=FR12%20PW` trả về product id `7` với tên `FR12 PW User Product Updated 20260629`. Sau khi ghi nhận bằng chứng, dữ liệu tạm đã được dọn bằng tài khoản admin.
