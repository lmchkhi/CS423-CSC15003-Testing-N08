# BUG-FR12-005: User thường có thể tạo category qua API category

## Found by Test Case
TC-FR12-PW-003

## Requirement liên quan
FR-12

## Severity / Priority
Critical / P1

## Environment
**Browser**: N/A - API test bằng curl  
**OS**: Ubuntu/Linux local environment  
**URL**: http://localhost:3000

## Steps to reproduce
1. Đăng nhập bằng user thường:
   `POST /api/login`
   body:
   `{"email":"test@eshop.com","password":"Test1234!"}`
2. Lấy JWT của user thường từ response login.
3. Gửi request:
   `POST /api/categories`
   với header:
   `Authorization: Bearer <valid-user-token>`
   và body:
   `{"name":"FR12 PW User Category 20260629"}`
4. Gọi `GET /api/categories` để kiểm tra category có được tạo hay không.

## Expected result
API phải từ chối request vì token hợp lệ nhưng không có `role = 'admin'`. Category mới không được tạo.

## Actual result
API trả về thành công và tạo category:

```http
HTTP/1.1 200 OK
```

```json
{"message":"Category created","id":7}
```

## Evidence
Sau request, `GET /api/categories` trả về category id `7` với tên `FR12 PW User Category 20260629`. Sau khi ghi nhận bằng chứng, dữ liệu tạm đã được dọn bằng tài khoản admin.
