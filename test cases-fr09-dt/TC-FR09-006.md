# Apply Inactive Coupon Code - Negative Path

## ID
TC-FR09-006

## Mô tả
Kiểm tra từ chối áp dụng mã giảm giá khi mã tồn tại trong CSDL nhưng bị vô hiệu hóa (is_active = 0). Người dùng đã đăng nhập, đơn hàng đủ ngưỡng, nhưng mã không hoạt động. Hệ thống phải từ chối với thông báo lỗi tương tự như mã không tồn tại.

## Môi trường kiểm thử
- OS: Windows 10 / macOS Monterey / Ubuntu 20.04
- Browser: Google Chrome Version 120+, Firefox 121+
- Backend: Node.js 18+ LTS
- Database: MySQL 8.0+ / PostgreSQL 14+
- API Environment: Staging / Production

## Precondition
1. Database có mã "INACTIVE_PROMO" trong bảng coupons với trạng thái vô hiệu:
   - code: "INACTIVE_PROMO"
   - discount_type: "percent"
   - discount_value: 15
   - min_order_amount: 200000
   - expired_at: 2099-12-31 (chưa hết hạn)
   - max_uses_per_user: 5
   - **is_active: 0** (vô hiệu hóa)

2. Người dùng đã xác thực thành công (có valid JWT token)

3. Người dùng chưa sử dụng mã này (nếu có tracking)

4. Đơn hàng có tổng tiền = 500,000 ₫ (vượt ngưỡng tối thiểu 200,000 ₫)

## Các điều kiện

- C1: Mã tồn tại - **Exist_Inactive** (mã tồn tại nhưng is_active = 0)
- C2: Còn hạn sử dụng - **Not_Expired** (expired_at = 2099-12-31, sau ngày hiện tại)
- C3: Đủ ngưỡng đơn hàng - **Above_Threshold** (500,000 >= 200,000)
- C4: Đã đăng nhập - **Valid_Token** (JWT token hợp lệ)
- C5: Chưa dùng hết lượt - **Within_Limit** (usage count = 0 < max_uses_per_user = 5)

## Các bước thực hiện

1. Người dùng điều hướng tới trang Checkout
2. Tại bước thanh toán, người dùng nhập mã giảm giá "INACTIVE_PROMO" vào trường input
3. Người dùng click nút "Áp dụng mã giảm giá" hoặc "Apply Coupon"
4. Hệ thống xử lý yêu cầu áp dụng mã

## Kết quả mong đợi

1. **Response status**: 400 Bad Request
2. **API Response body**:
   ```json
   {
     "success": false,
     "error_code": "COUPON_INACTIVE",
     "message": "Mã giảm giá 'INACTIVE_PROMO' không còn hoạt động",
     "coupon_code": "INACTIVE_PROMO"
   }
   ```
   Hoặc (đồng nhất với mã không tồn tại):
   ```json
   {
     "success": false,
     "error_code": "COUPON_NOT_FOUND",
     "message": "Mã giảm giá 'INACTIVE_PROMO' không tồn tại hoặc không còn hoạt động"
   }
   ```

3. **UI Updates**:
   - Trường mã giảm giá không bị khóa
   - Hiển thị thông báo lỗi (màu đỏ): "Mã giảm giá 'INACTIVE_PROMO' không còn hoạt động"
   - Tổng tiền vẫn giữ nguyên (500,000 ₫)
   - Button "Thanh toán" vẫn kích hoạt

4. **Database verification**:
   - Bảng coupon_usage không có record mới
   - Bảng coupons không được update (is_active vẫn = 0)

5. **Log verification**:
   - Server logs ghi nhận: `[WARN] Coupon validation failed: code=INACTIVE_PROMO, user_id=xxx, reason=COUPON_INACTIVE`
