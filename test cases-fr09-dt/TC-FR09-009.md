# Apply Coupon When Order At Minimum Threshold - Boundary Condition

## ID
TC-FR09-009

## Mô tả
Kiểm tra áp dụng thành công mã giảm giá khi tổng đơn hàng **chính xác bằng** ngưỡng tối thiểu (at boundary). Mã SAVE10 có min_order_amount = 300,000 ₫, tổng đơn hàng = 300,000 ₫ (exact). Điều kiện `>=` (lớn hơn hoặc bằng) trong spec phải được kiểm tra. Đây là điều kiện biên quan trọng.

## Môi trường kiểm thử
- OS: Windows 10 / macOS Monterey / Ubuntu 20.04
- Browser: Google Chrome Version 120+, Firefox 121+
- Backend: Node.js 18+ LTS
- Database: MySQL 8.0+ / PostgreSQL 14+
- API Environment: Staging / Production

## Precondition
1. Database có mã SAVE10 trong bảng coupons:
   - code: "SAVE10"
   - discount_type: "percent"
   - discount_value: 10
   - min_order_amount: 300000
   - expired_at: 2099-12-31 (chưa hết hạn)
   - max_uses_per_user: 1
   - is_active: 1

2. Người dùng đã xác thực thành công (có valid JWT token)

3. Người dùng chưa sử dụng mã SAVE10 (usage count = 0)

4. Đơn hàng có tổng tiền = 300,000 ₫ (chính xác bằng ngưỡng tối thiểu)

## Các điều kiện

- C1: Mã tồn tại - **Exists_Active** (SAVE10 tồn tại và hoạt động)
- C2: Còn hạn sử dụng - **Not_Expired** (expired_at = 2099-12-31, sau ngày hiện tại)
- C3: Đủ ngưỡng đơn hàng - **At_Threshold** (300,000 == 300,000, thỏa mãn >=)
- C4: Đã đăng nhập - **Valid_Token** (JWT token hợp lệ)
- C5: Chưa dùng hết lượt - **Within_Limit** (usage count = 0 < max_uses_per_user = 1)
