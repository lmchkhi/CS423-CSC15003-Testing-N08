# Apply Coupon Without JWT Token - Authentication Negative Path

## ID
TC-FR09-010

## Mô tả
Kiểm tra từ chối áp dụng mã giảm giá khi người dùng chưa đăng nhập hoặc không có JWT token. Spec yêu cầu "Người dùng phải có JWT Token hợp lệ" (C4). Mặc dù mã hợp lệ, đơn hàng đủ tiền, nhưng thiếu xác thực. Hệ thống phải từ chối và ưu tiên lỗi authentication.

## Môi trường kiểm thử
- OS: Windows 10 / macOS Monterey / Ubuntu 20.04
- Browser: Google Chrome Version 120+, Firefox 121+
- Backend: Node.js 18+ LTS
- Database: MySQL 8.0+ / PostgreSQL 14+
- API Environment: Staging / Production

## Precondition
1. Database có mã SAVE10 và các mã hợp lệ khác

2. Người dùng **chưa đăng nhập** hoặc không có JWT token hợp lệ:
   - Không có header Authorization
   - Không có session/cookie chứa token
   - Token header trống ("Authorization: ")

3. Đơn hàng có tổng tiền = 500,000 ₫ (đủ tiền)

4. Trạng thái client: chưa hoặc vừa logout

## Các điều kiện

- C1: Mã tồn tại - **Exists_Active** (SAVE10 tồn tại và hoạt động)
- C2: Còn hạn sử dụng - **Not_Expired** (expired_at = 2099-12-31, sau ngày hiện tại)
- C3: Đủ ngưỡng đơn hàng - **Above_Threshold** (500,000 >= 300,000)
- C4: Đã đăng nhập - **No_Token** (không có token, không xác thực)
- C5: Chưa dùng hết lượt - **Within_Limit** (giả định nếu được xác thực)

## Các bước thực hiện

### Scenario A: Không có Authorization Header
1. Người dùng chưa đăng nhập
2. Điều hướng tới trang Checkout (hoặc đã logout)
3. Nhập mã giảm giá "SAVE10" vào trường input
4. Click nút "Áp dụng mã giảm giá"
5. Hệ thống xử lý yêu cầu (không có header Authorization)

### Scenario B: Authorization header trống
1. Người dùng đã logout
2. Session/cookie bị xóa
3. Nhập mã giảm giá "SAVE10"
4. Click nút "Áp dụng"
5. Request gửi với header Authorization: "" (trống)

## Kết quả mong đợi

1. **Response status**: 401 Unauthorized (hoặc 403 Forbidden)
2. **API Response body**:
   ```json
   {
     "success": false,
     "error_code": "UNAUTHORIZED",
     "message": "Vui lòng đăng nhập để áp dụng mã giảm giá"
   }
   ```
   Hoặc:
   ```json
   {
     "success": false,
     "error_code": "MISSING_TOKEN",
     "message": "JWT Token không hợp lệ hoặc không được cung cấp"
   }
   ```

3. **UI Updates**:
   - Trường mã giảm giá không bị khóa
   - Hiển thị thông báo lỗi (màu đỏ): "Vui lòng đăng nhập để sử dụng mã giảm giá"
   - Có thể hiển thị nút "Đăng nhập" để user xác thực
   - Tổng tiền vẫn giữ nguyên, không áp dụng giảm giá
   - Button "Thanh toán" có thể bị disable hoặc yêu cầu login trước

4. **Database verification**:
   - Bảng coupon_usage không có record mới
   - Không có audit log cho action này (vì user chưa xác thực)

5. **Log verification**:
   - Server logs ghi nhận: `[WARN] Coupon request rejected: reason=UNAUTHORIZED, missing_token=true`
