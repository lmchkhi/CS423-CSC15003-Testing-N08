# Apply Coupon When Order Below Minimum Amount - Negative Path

## ID
TC-FR09-008

## Mô tả
Kiểm tra từ chối áp dụng mã giảm giá khi tổng đơn hàng không đạt ngưỡng tối thiểu. Mã SAVE10 có min_order_amount = 300,000 ₫, nhưng tổng đơn hàng chỉ = 200,000 ₫. Người dùng đã đăng nhập, mã hợp lệ, còn hạn, nhưng không đủ điều kiện tiền. Hệ thống phải từ chối.

## Môi trường kiểm thử
- OS: Windows 10 / macOS Monterey / Ubuntu 20.04
- Browser: Google Chrome Version 120+, Firefox 121+
- Backend: Node.js 18+ LTS
- Database: MySQL 8.0+ / PostgreSQL 14+
- API Environment: Staging / Production

## Precondition
1. Database có mã SAVE10 trong bảng coupons:
   - code: "SAVE10"
   - discount_type: "percent"
   - discount_value: 10
   - min_order_amount: 300000
   - expired_at: 2099-12-31 (chưa hết hạn)
   - max_uses_per_user: 1
   - is_active: 1

2. Người dùng đã xác thực thành công (có valid JWT token)

3. Người dùng chưa sử dụng mã SAVE10 (usage count = 0)

4. Đơn hàng có tổng tiền = 200,000 ₫ (dưới ngưỡng tối thiểu 300,000 ₫)

## Các điều kiện

- C1: Mã tồn tại - **Exists_Active** (SAVE10 tồn tại và hoạt động)
- C2: Còn hạn sử dụng - **Not_Expired** (expired_at = 2099-12-31, sau ngày hiện tại)
- C3: Đủ ngưỡng đơn hàng - **Below_Threshold** (200,000 < 300,000)
- C4: Đã đăng nhập - **Valid_Token** (JWT token hợp lệ)
- C5: Chưa dùng hết lượt - **Within_Limit** (usage count = 0 < max_uses_per_user = 1)

## Các bước thực hiện

1. Người dùng điều hướng tới trang Checkout
2. Đơn hàng hiện tại có tổng tiền = 200,000 ₫
3. Tại bước thanh toán, người dùng nhập mã giảm giá "SAVE10" vào trường input
4. Người dùng click nút "Áp dụng mã giảm giá" hoặc "Apply Coupon"
