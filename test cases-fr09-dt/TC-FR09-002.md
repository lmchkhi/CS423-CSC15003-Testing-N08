# Apply BIGBUY Fixed Discount - Happy Path

## ID
TC-FR09-002

## Mô tả
Kiểm tra áp dụng mã giảm giá loại fixed (BIGBUY) thành công khi tất cả điều kiện hợp lệ. Người dùng đã đăng nhập, mã giảm giá có tồn tại, còn hạn sử dụng, đơn hàng đủ ngưỡng tối thiểu, chưa dùng hết lượt. Hệ thống phải tính toán giảm giá chính xác theo công thức: `discount_amount = discount_value` (cố định).

## Môi trường kiểm thử
- OS: Windows 10 / macOS Monterey / Ubuntu 20.04
- Browser: Google Chrome Version 120+, Firefox 121+
- Backend: Node.js 18+ LTS
- Database: MySQL 8.0+ / PostgreSQL 14+
- API Environment: Staging / Production

## Precondition
1. Database có mã BIGBUY trong bảng coupons với trạng thái hoạt động (is_active = 1):
   - code: "BIGBUY"
   - discount_type: "fixed"
   - discount_value: 50000
   - min_order_amount: 500000
   - expired_at: 2099-12-31 (chưa hết hạn)
   - max_uses_per_user: 1

2. Người dùng đã xác thực thành công (có valid JWT token trong session/cookie)

3. Người dùng chưa sử dụng mã BIGBUY lần nào (usage count = 0)

4. Đơn hàng có tổng tiền = 700,000 ₫ (vượt ngưỡng tối thiểu 500,000 ₫)

## Các điều kiện

- C1: Mã tồn tại - **Exists_Active** (BIGBUY tồn tại và hoạt động)
- C2: Còn hạn sử dụng - **Not_Expired** (expired_at = 2099-12-31, sau ngày hiện tại)
- C3: Đủ ngưỡng đơn hàng - **Above_Threshold** (700,000 >= 500,000)
- C4: Đã đăng nhập - **Valid_Token** (JWT token hợp lệ)
- C5: Chưa dùng hết lượt - **Within_Limit** (usage count = 0 < max_uses_per_user = 1)
