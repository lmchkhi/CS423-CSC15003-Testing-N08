# Percent Discount Calculation Verification - Min Threshold

## ID
TC-FR09-014

## Mô tả
Kiểm tra chính xác công thức tính toán giảm giá loại percent: `discount_amount = total × discount_value / 100`. Test case này xác minh:
1. Công thức được tính toán đúng
2. Kết quả không bị làm tròn sai
3. Tính toán hoạt động chính xác tại ngưỡng tối thiểu (boundary)

Mã SAVE10 (10%) được áp dụng trên tổng đơn hàng = 300,000 ₫ (chính xác ngưỡng min).
Expected: discount = 300,000 × 10 / 100 = 30,000 ₫, final = 270,000 ₫

## Môi trường kiểm thử
- OS: Windows 10 / macOS Monterey / Ubuntu 20.04
- Browser: Google Chrome Version 120+, Firefox 121+
- Backend: Node.js 18+ LTS
- Database: MySQL 8.0+ / PostgreSQL 14+
- API Environment: Staging / Production

## Precondition
1. Database có mã SAVE10:
   - code: "SAVE10"
   - discount_type: "percent"
   - discount_value: 10
   - min_order_amount: 300000
   - expired_at: 2099-12-31 (chưa hết hạn)
   - max_uses_per_user: 1
   - is_active: 1

2. Người dùng đã xác thực (valid JWT token)

3. Người dùng chưa sử dụng mã SAVE10 (usage = 0)

4. Đơn hàng có tổng tiền = 300,000 ₫ (chính xác ngưỡng min)

5. Tất cả điều kiện khác hợp lệ (không expired, được đăng nhập, etc.)

## Các điều kiện

- C1: Mã tồn tại - **Exists_Active** (SAVE10)
- C2: Còn hạn sử dụng - **Not_Expired**
- C3: Đủ ngưỡng đơn hàng - **At_Threshold** (300,000 == 300,000)
- C4: Đã đăng nhập - **Valid_Token**
- C5: Chưa dùng hết lượt - **Within_Limit**

### Calculation verification:
```
Công thức: discount_amount = total × discount_value / 100
Input: 300,000 × 10 / 100
Tính toán: 3,000,000 / 100 = 30,000 ₫
Final amount: 300,000 - 30,000 = 270,000 ₫

Kiểm tra:
- discount_amount = 30,000 (exactly)
- final_amount = 270,000 (exactly)
- Không có rounding error
```
