# Error Priority Test - Authentication Before Expiration

## ID
TC-FR09-013

## Mô tả
Kiểm tra thứ tự ưu tiên xử lý lỗi. Khi có nhiều điều kiện thất bại, hệ thống phải check authentication (C4) **trước** các điều kiện khác, bao gồm cả kiểm tra expiration (C2). Scenario này có 2 lỗi:
- C2: Coupon expired (hết hạn)
- C4: No token (chưa xác thực)

Hệ thống phải trả về lỗi UNAUTHORIZED, không phải EXPIRED. Spec định nghĩa validation order: Auth → Code validity → Expiration → Amount → Limit.

## Môi trường kiểm thử
- OS: Windows 10 / macOS Monterey / Ubuntu 20.04
- Browser: Google Chrome Version 120+, Firefox 121+
- Backend: Node.js 18+ LTS
- Database: MySQL 8.0+ / PostgreSQL 14+
- API Environment: Staging / Production

## Precondition
1. Database có mã EXPIRED trong bảng coupons:
   - code: "EXPIRED"
   - discount_type: "percent"
   - discount_value: 20
   - min_order_amount: 100000
   - expired_at: 2020-01-01 (đã quá hạn)
   - max_uses_per_user: 1
   - is_active: 1

2. Người dùng **chưa đăng nhập** hoặc không có valid JWT token:
   - Không có header Authorization
   - Hoặc token trống

3. Đơn hàng có tổng tiền = 400,000 ₫

## Các điều kiện

- C1: Mã tồn tại - **Exists_Active** (EXPIRED tồn tại và hoạt động)
- C2: Còn hạn sử dụng - **Expired** (expired_at = 2020-01-01 < 2026-06-29)
- C3: Đủ ngưỡng đơn hàng - **Above_Threshold** (400,000 >= 100,000)
- C4: Đã đăng nhập - **No_Token** (không có token)
- C5: Chưa dùng hết lượt - **Within_Limit** (giả định)

**Lỗi hiện diện**: C2 (Expired) + C4 (No_Token)
**Lỗi kỳ vọng được trả về**: C4 (Authentication error), không phải C2 (Expired error)

## Các bước thực hiện

1. Người dùng chưa đăng nhập (logout)
2. Điều hướng tới trang Checkout
3. Nhập mã giảm giá "EXPIRED" vào trường input
4. Click nút "Áp dụng mã giảm giá" hoặc "Apply Coupon"
5. Hệ thống xử lý yêu cầu (có 2 lỗi: không token + coupon expired)

## Kết quả mong đợi

1. **Response status**: 401 Unauthorized (không phải 400)
2. **API Response body** (Authentication error, NOT Expired error):
   ```json
   {
     "success": false,
     "error_code": "UNAUTHORIZED",
     "message": "Vui lòng đăng nhập để áp dụng mã giảm giá"
   }
   ```

   **KHÔNG nên trả về:**
   ```json
   {
     "success": false,
     "error_code": "COUPON_EXPIRED",
     "message": "Mã giảm giá 'EXPIRED' đã hết hạn sử dụng"
   }
   ```

3. **UI Updates**:
   - Hiển thị thông báo lỗi: "Vui lòng đăng nhập để sử dụng mã giảm giá"
   - Không hiển thị thông báo về coupon expired
   - Có thể hiển thị nút "Đăng nhập"
   - Tổng tiền vẫn giữ nguyên

4. **Database verification**:
   - Bảng coupon_usage không có record mới

5. **Log verification**:
   - Server logs ghi nhận: `[WARN] Coupon request rejected: reason=UNAUTHORIZED, missing_token=true`
   - **KHÔNG nên** ghi: `reason=COUPON_EXPIRED`
