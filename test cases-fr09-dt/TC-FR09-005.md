# Apply Non-Existent Coupon Code - Negative Path

## ID
TC-FR09-005

## Mô tả
Kiểm tra từ chối áp dụng mã giảm giá khi mã không tồn tại trong CSDL. Người dùng đã đăng nhập, đơn hàng đủ ngưỡng, nhưng mã nhập vào không có trong bảng coupons. Hệ thống phải từ chối với thông báo lỗi rõ ràng.

## Môi trường kiểm thử
- OS: Windows 10 / macOS Monterey / Ubuntu 20.04
- Browser: Google Chrome Version 120+, Firefox 121+
- Backend: Node.js 18+ LTS
- Database: MySQL 8.0+ / PostgreSQL 14+
- API Environment: Staging / Production

## Precondition
1. Mã "NOTEXIST" không tồn tại trong bảng coupons

2. Các mã hợp lệ khác (SAVE10, BIGBUY, VIP100, EXPIRED) đã tồn tại để đảm bảo DB hoạt động

3. Người dùng đã xác thực thành công (có valid JWT token)

4. Đơn hàng có tổng tiền = 600,000 ₫

## Các điều kiện

- C1: Mã tồn tại - **Not_Exist** (mã không có trong CSDL)
- C2: Còn hạn sử dụng - **Not_Expired** (giả định nếu mã tồn tại)
- C3: Đủ ngưỡng đơn hàng - **Above_Threshold** (600,000 >= 0)
- C4: Đã đăng nhập - **Valid_Token** (JWT token hợp lệ)
- C5: Chưa dùng hết lượt - **Within_Limit** (giả định nếu mã tồn tại)

## Kết quả mong đợi

1. **Response status**: 400 Bad Request (hoặc 404 Not Found)
2. **API Response body**:
   ```json
   {
     "success": false,
     "error_code": "COUPON_NOT_FOUND",
     "message": "Mã giảm giá 'NOTEXIST' không tồn tại hoặc không còn hoạt động",
     "coupon_code": "NOTEXIST"
   }
   ```
   Hoặc:
   ```json
   {
     "success": false,
     "error_code": "INVALID_COUPON",
     "message": "Mã giảm giá không hợp lệ"
   }
   ```

3. **UI Updates**:
   - Trường mã giảm giá không bị khóa, user có thể xóa hoặc sửa
   - Hiển thị thông báo lỗi (màu đỏ): "Mã giảm giá 'NOTEXIST' không tồn tại"
   - Tổng tiền vẫn giữ nguyên (600,000 ₫), không áp dụng giảm giá
   - Button "Thanh toán" vẫn kích hoạt

4. **Database verification**:
   - Bảng coupon_usage không có record mới
   - Không có query update nào trong logs

5. **Log verification**:
   - Server logs ghi nhận: `[WARN] Coupon validation failed: code=NOTEXIST, user_id=xxx, reason=COUPON_NOT_FOUND`
