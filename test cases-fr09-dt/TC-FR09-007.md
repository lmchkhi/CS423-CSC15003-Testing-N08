# Apply Expired Coupon Code - Negative Path

## ID
TC-FR09-007

## Mô tả
Kiểm tra từ chối áp dụng mã giảm giá khi mã đã hết hạn sử dụng. Mã EXPIRED trong bảng coupons có expired_at = 2020-01-01, trước ngày hiện tại (2026-06-29). Mã tồn tại, hoạt động, nhưng đã quá hạn. Hệ thống phải từ chối với thông báo lỗi phù hợp.

## Môi trường kiểm thử
- OS: Windows 10 / macOS Monterey / Ubuntu 20.04
- Browser: Google Chrome Version 120+, Firefox 121+
- Backend: Node.js 18+ LTS
- Database: MySQL 8.0+ / PostgreSQL 14+
- API Environment: Staging / Production

## Precondition
1. Database có mã EXPIRED trong bảng coupons:
   - code: "EXPIRED"
   - discount_type: "percent"
   - discount_value: 20
   - min_order_amount: 100000
   - expired_at: 2020-01-01 (đã quá hạn)
   - max_uses_per_user: 1
   - is_active: 1 (vẫn hoạt động trong hệ thống)

2. Ngày hiện tại: 2026-06-29 (sau 2020-01-01)

3. Người dùng đã xác thực thành công (có valid JWT token)

4. Người dùng chưa sử dụng mã EXPIRED (usage count = 0)

5. Đơn hàng có tổng tiền = 400,000 ₫ (vượt ngưỡng tối thiểu 100,000 ₫)

## Các điều kiện

- C1: Mã tồn tại - **Exists_Active** (EXPIRED tồn tại và đang hoạt động trong DB)
- C2: Còn hạn sử dụng - **Expired** (expired_at = 2020-01-01 < 2026-06-29)
- C3: Đủ ngưỡng đơn hàng - **Above_Threshold** (400,000 >= 100,000)
- C4: Đã đăng nhập - **Valid_Token** (JWT token hợp lệ)
- C5: Chưa dùng hết lượt - **Within_Limit** (usage count = 0 < max_uses_per_user = 1)

1. Người dùng điều hướng tới trang Checkout
2. Tại bước thanh toán, người dùng nhập mã giảm giá "EXPIRED" vào trường input
