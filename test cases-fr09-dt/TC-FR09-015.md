# Fixed Discount Calculation Verification - High-Value Order

## ID
TC-FR09-015

## Mô tả
Kiểm tra chính xác công thức tính toán giảm giá loại fixed: `discount_amount = discount_value` (cố định, không phụ thuộc vào tổng tiền). Test case này xác minh:
1. Công thức fixed không tính toán dựa trên phần trăm
2. Giảm giá là một giá trị cố định bất kể đơn hàng lớn hay nhỏ
3. Kết quả không bị thay đổi dù có các biến động khác

Mã BIGBUY (50,000 ₫ cố định) được áp dụng trên tổng đơn hàng = 1,500,000 ₫ (cao).
Expected: discount = 50,000 ₫ (cố định), final = 1,450,000 ₫

## Môi trường kiểm thử
- OS: Windows 10 / macOS Monterey / Ubuntu 20.04
- Browser: Google Chrome Version 120+, Firefox 121+
- Backend: Node.js 18+ LTS
- Database: MySQL 8.0+ / PostgreSQL 14+
- API Environment: Staging / Production

## Precondition
1. Database có mã BIGBUY:
   - code: "BIGBUY"
   - discount_type: "fixed"
   - discount_value: 50000
   - min_order_amount: 500000
   - expired_at: 2099-12-31 (chưa hết hạn)
   - max_uses_per_user: 1
   - is_active: 1

2. Người dùng đã xác thực (valid JWT token)

3. Người dùng chưa sử dụng mã BIGBUY (usage = 0)

4. Đơn hàng có tổng tiền = 1,500,000 ₫ (cao, 3x ngưỡng min)

5. Tất cả điều kiện khác hợp lệ

## Các điều kiện

- C1: Mã tồn tại - **Exists_Active** (BIGBUY)
- C2: Còn hạn sử dụng - **Not_Expired**
- C3: Đủ ngưỡng đơn hàng - **Above_Threshold** (1,500,000 >= 500,000)
- C4: Đã đăng nhập - **Valid_Token**
- C5: Chưa dùng hết lượt - **Within_Limit**

### Calculation verification:
```
Công thức: discount_amount = discount_value (cố định)
Input: discount_value = 50,000 ₫
Tính toán: discount_amount = 50,000 ₫ (bất kể total là bao nhiêu)
Final amount: 1,500,000 - 50,000 = 1,450,000 ₫

So sánh với percent discount (để chứng minh sự khác biệt):
- Nếu là percent: 1,500,000 × 10 / 100 = 150,000 ₫ (lớn hơn)
- Nhưng BIGBUY là fixed: luôn là 50,000 ₫ (nhỏ hơn)

Kiểm tra:
- discount_amount = 50,000 (chính xác, cố định)
- final_amount = 1,450,000 (chính xác)
- Không phụ thuộc vào total
```

## Comparison table (Fixed vs Percent)

| Tham số | Fixed (BIGBUY) | Percent (SAVE10) | Khác biệt |
|---------|---|---|---|
| discount_value | 50,000 ₫ | 10% | Cố định vs tỷ lệ |
| order_total | 1,500,000 ₫ | 1,500,000 ₫ | Giống nhau |
| discount_amount | 50,000 ₫ | 150,000 ₫ | Fixed không phụ thuộc total |
| final_total | 1,450,000 ₫ | 1,350,000 ₫ | Khác nhau |
| Tính chất | Không thay đổi với total | Phụ thuộc vào total | Trái ngược |
