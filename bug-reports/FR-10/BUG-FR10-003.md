## Found by Test Case

TC-FR10-DTT-012

## Requirement liên quan

FR-10 — Trạng thái Đơn hàng (Order State Machine), FR-12 — Kiểm soát truy cập (Access Control), SEC-03

## Severity / Priority

Critical / P0

## Environment

- API Tool: Postman / cURL
- OS: Windows
- Backend: http://localhost:3000
- API: PUT /api/admin/orders/:id/status

## Steps to reproduce

1. Đăng nhập với tài khoản User (test@eshop.com / Test1234!) qua API: `POST /api/login`
2. Lấy Bearer Token của User từ response
3. Tìm một đơn hàng đang ở trạng thái `pending` (qua API: `GET /api/orders/my-orders`)
4. Sử dụng Postman hoặc cURL để gọi API Admin:
   ```
   PUT http://localhost:3000/api/admin/orders/:id/status
   Header: Authorization: Bearer <user_token>
   Body: {"status": "confirmed"}
   ```
5. Quan sát phản hồi từ hệ thống
6. Kiểm tra lại trạng thái đơn hàng

## Expected result

Theo đặc tả FR-12 và SEC-03:

> "Tất cả các API Admin (`/api/admin/*`) đều phải yêu cầu: (1) Token JWT hợp lệ, (2) `role = 'admin'` trong Token."

- ❌ Hệ thống **từ chối** yêu cầu do không đủ quyền
- API trả về **HTTP 401/403** với thông báo lỗi phù hợp
- Đơn hàng **vẫn giữ nguyên** trạng thái `pending`
- Hệ thống kiểm tra `role = admin` trong JWT Token

## Actual result

- Hệ thống **đồng ý cho phép** User xác nhận đơn hàng pending thành confirmed
- API trả về **HTTP 200 OK** với thông tin đơn hàng đã cập nhật
- Đơn hàng bị chuyển từ `pending` sang `confirmed` bởi User — vi phạm State Machine
- API `/api/admin/orders/:id/status` **KHÔNG kiểm tra `role = admin`** trong JWT Token

## Root Cause Analysis (Giả thuyết)

API endpoint `PUT /api/admin/orders/:id/status` có thể **thiếu middleware kiểm tra role Admin**. Code backend có thể chỉ kiểm tra token tồn tại mà không verify role:

```javascript
// Hiện tại (có thể):
router.put('/api/admin/orders/:id/status', authMiddleware, updateOrderStatus);

// Cần thêm:
router.put('/api/admin/orders/:id/status', authMiddleware, adminMiddleware, updateOrderStatus);

// Trong đó adminMiddleware kiểm tra:
function adminMiddleware(req, res, next) {
  if (req.user.role !== 'admin') {
    return res.status(403).json({ error: 'Yêu cầu quyền Admin' });
  }
  next();
}
```

## Impact

- **Mức độ ảnh hưởng:** Critical — vi phạm cả Access Control (FR-12) và State Machine (FR-10) và Security (SEC-03)
- **Phạm vi:** Tất cả API dưới `/api/admin/orders/*` có thể bị User thường truy cập
- **Hậu quả:**
  - Bất kỳ User nào cũng có thể tự xác nhận, giao hàng, hoàn tất đơn hàng
  - Mất quyền kiểm soát quản trị — Admin không còn độc quyền quản lý đơn hàng
  - Rủi ro bảo mật cao — User có thể thao túng trạng thái đơn hàng
  - Vi phạm nguyên tắc "Least Privilege" — User có quyền vượt tầm
  - Có thể ảnh hưởng đến tính toàn vẹn dữ liệu của hệ thống
