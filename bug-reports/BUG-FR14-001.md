# BUG-FR14-001: User thường có thể thêm, sửa và xóa danh mục qua API

## Found by Test Case
TC-FR14-DT-005, TC-FR14-DT-013, TC-FR14-DT-016

## Requirement liên quan
FR-12, FR-14

## Severity / Priority
Critical / P1

## Environment
**Browser**: Chrome 1xx  
**OS**: Ubuntu 22.04  
**Admin URL**: http://localhost:5174  
**API URL**: http://localhost:3000  
**Build / Commit**: `5164f72`

## Steps to reproduce
1. Đăng nhập bằng user thường `test@eshop.com` để lấy JWT có `role = 'user'`.
2. Gọi `POST /api/categories` với user token và body `{"name":"FR14_VERIFY_USER_CREATE"}`.
3. Gọi `PUT /api/categories/<category_id>` với user token và body `{"name":"FR14_VERIFY_USER_UPDATE"}`.
4. Gọi `DELETE /api/categories/<category_id>` với user token.
5. Quan sát HTTP status, response body và danh sách danh mục.

## Expected result
Các API có tính ảnh hưởng dữ liệu `POST/PUT/DELETE /api/categories` phải yêu cầu JWT hợp lệ có `role = 'admin'`; token user thường phải bị từ chối và không được tạo/sửa/xóa danh mục.

## Actual result
API chấp nhận token user thường cho cả thêm, sửa và xóa danh mục. Các request trả `200 OK` với message thành công như `Category created`, `Category updated`, `Category deleted`.
