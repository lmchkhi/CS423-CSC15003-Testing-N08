# [BUG][FR-08 Checkout] Missing input validation for total_amount in checkout

## Found by Test Case
FR-08 Checkout API test case — phân tích giá trị biên phát hiện hệ thống chấp nhận số tiền âm và bằng 0

## Requirement liên quan
FR-08 Checkout: `total_amount` phải là số dương (`> 0`). Hệ thống phải từ chối yêu cầu có `total_amount <= 0` hoặc không hợp lệ và trả `400 Bad Request`.

## Severity / Priority
High / P1

## Environment
**Tool**: Postman collection v2.1 / Newman headless
**Collection**: `api/collections/eshop-hw06.postman_collection.json`
**Environment file**: `api/environments/local.postman_environment.json` (`baseUrl = http://localhost:3000`)
**Observed request host**: `http://127.0.0.1:3000` trong collection/Newman logs
**Folder / data / report**: `FR-08 Checkout`, `api/data/checkout-cases.json`, `api/newman/fr08-checkout-report.html`
**Endpoint involved**: `POST /api/checkout`
**Anti-cheat header**: `X-Student-Id: 23127300`
**OS / Hardware / build**: Không được ghi nhận trong Newman artifact nộp; không dùng làm bằng chứng cho bug này.

## Steps to reproduce
1. Gửi `POST /api/login` với thông tin đăng nhập hợp lệ để lấy JWT token.
2. Gửi `POST /api/checkout` với `total_amount = -5000`.
3. Quan sát hệ thống trả `200 OK` và tạo đơn hàng thành công.

## Expected result
Yêu cầu có `total_amount <= 0` phải bị từ chối với `400 Bad Request`, kèm thông báo như `"total_amount must be a positive number"` hoặc nội dung tương đương.

## Actual result
Hệ thống chấp nhận `total_amount` âm, tạo đơn hàng mới và trả `200 OK`. Đơn hàng được lưu vào database với giá trị âm.

## Evidence
```bash
# Đăng nhập để lấy token
curl -X POST http://127.0.0.1:3000/api/login \
  -H "Content-Type: application/json" \
  -H "X-Student-Id: 23127300" \
  -d '{"email":"bugtester@test.com","password":"Pass123!"}'

Phản hồi: {"message":"Login successful","token":"eyJhbGci..."}

# Checkout với total_amount âm
curl -X POST http://127.0.0.1:3000/api/checkout \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." \
  -H "X-Student-Id: 23127300" \
  -d '{"total_amount":-5000,"shipping_address":"123 Test St"}'

Phản hồi: 200 OK
{"message":"Checkout successful","orderId":3}
```

Cho phép tạo đơn hàng với `total_amount` âm dẫn đến:
- Dữ liệu không nhất quán trong database.
- Có thể làm sai báo cáo doanh thu và thống kê.
- Có thể bị lợi dụng để gian lận hoặc làm lệch số liệu tài chính.
