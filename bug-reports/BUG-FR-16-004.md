# BUG-FR-16-004: Hệ thống cho phép import sản phẩm thành công khi trường price bằng 0

## Found by Test Case
- TC-FR-16-006
- TC-FR-16-014

## Requirement liên quan
FR-16: Import Sản phẩm từ CSV

## Related Github issue
Issue #27

## Severity / Priority
High / P2

## Environment
- **Browser**: Zen Browser 1.21.3b (Firefox 152.0.1)
- **OS**: Fedora 44
- **URL**: http://localhost:5174/

## Steps to reproduce
1. Đăng nhập vào hệ thống với tài khoản Admin.
2. Truy cập trang Import sản phẩm từ CSV.
3. Chọn file `products_price_zero.csv` (dòng 3 có `price` bằng 0) để tải lên.
4. Bấm nút Import.

## Expected result
Import thất bại. Toàn bộ giao dịch bị rollback — không có sản phẩm nào được lưu. Báo cáo hiển thị: 0 dòng thành công, 1 dòng lỗi (dòng 3: price phải là số dương).

## Actual result
Import thành công không báo lỗi, sản phẩm có `price` bằng 0 vẫn được import vào hệ thống.
