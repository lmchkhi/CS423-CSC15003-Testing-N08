# BUG-FR08-001: IDOR vulnerability in GET /api/orders/:id endpoint

## Found by Test Case
FR-08 Checkout API test case — IDOR security test detecting unauthorized order access without authentication

## Requirement liên quan
FR-08 Checkout + SEC-01 Authentication: GET /api/orders/:id phải yêu cầu JWT token hợp lệ, trả về 401 nếu không có Authorization header

## Severity / Priority
Critical / P0

## Environment
**Tool**: Postman / Newman 11.x
**OS / Hardware**: macOS 15.5, Apple Silicon M1, 8GB RAM
**SUT**: EShop backend, http://127.0.0.1:3000/api/orders/:id
**Student ID**: 23127300

## Steps to reproduce
1. POST /api/checkout với token hợp lệ để tạo order, nhận orderId = 2
2. GET /api/orders/2 **không có Authorization header**
3. Hệ thống trả về 200 OK với đầy đủ thông tin đơn hàng

## Expected result
Request không có Authorization header phải bị từ chối với HTTP 401 Unauthorized và message "Unauthorized" hoặc "Token required"

## Actual result
Hệ thống trả về 200 OK với đầy đủ thông tin đơn hàng bao gồm user_id, total_amount, status, shipping_address. Bất kỳ ai biết orderId đều có thể đọc thông tin đơn hàng mà không cần xác thực.

## Evidence
```bash
# Create order with valid token
curl -X POST http://127.0.0.1:3000/api/checkout \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." \
  -H "X-Student-Id: 23127300" \
  -d '{"total_amount":200000,"shipping_address":"123 Test St"}'

Response: {"message":"Checkout successful","orderId":2}

# Access order WITHOUT Authorization header (IDOR vulnerability)
curl -X GET http://127.0.0.1:3000/api/orders/2 \
  -H "X-Student-Id: 23127300"

Response: 200 OK
{
  "id": 2,
  "user_id": 5,
  "total_amount": 200000,
  "status": "pending",
  "shipping_address": "123 Test St",
  "created_at": "2026-08-20 12:15:15"
}
```

Attacker có thể duyệt qua các orderId (1, 2, 3, ...) để thu thập thông tin đơn hàng của tất cả người dùng mà không cần đăng nhập.
