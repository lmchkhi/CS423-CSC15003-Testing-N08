# [BUG][FR-08 Checkout] IDOR vulnerability in GET /api/orders/:id endpoint

## Found by Test Case
FR-08 Checkout API test case — kiểm thử bảo mật IDOR phát hiện truy cập đơn hàng không cần xác thực

## Requirement liên quan
FR-08 Checkout + SEC-01 Authentication: `GET /api/orders/:id` phải yêu cầu JWT token hợp lệ và trả `401 Unauthorized` nếu thiếu header `Authorization`.

## Severity / Priority
Critical / P0

## Environment
**Tool**: Postman collection v2.1 / Newman headless
**Collection**: `api/collections/eshop-hw06.postman_collection.json`
**Environment file**: `api/environments/local.postman_environment.json` (`baseUrl = http://localhost:3000`)
**Observed request host**: `http://127.0.0.1:3000` trong collection/Newman logs
**Folder / report**: `FR-08 State & Security`, `api/newman/fr08-state-report.html`
**Endpoint involved**: `GET /api/orders/:id`
**Anti-cheat header**: `X-Student-Id: 23127300`
**OS / Hardware / build**: Không được ghi nhận trong Newman artifact nộp; không dùng làm bằng chứng cho bug này.

## Steps to reproduce
1. Gửi `POST /api/checkout` với token hợp lệ để tạo đơn hàng, nhận `orderId = 2`.
2. Gửi `GET /api/orders/2` nhưng không gửi header `Authorization`.
3. Quan sát hệ thống trả `200 OK` với đầy đủ thông tin đơn hàng.

## Expected result
Yêu cầu không có header `Authorization` phải bị từ chối với `401 Unauthorized`, kèm thông báo như `"Unauthorized"` hoặc `"Token required"`.

## Actual result
Hệ thống trả `200 OK` với đầy đủ thông tin đơn hàng, bao gồm `user_id`, `total_amount`, `status`, `shipping_address`. Bất kỳ ai biết `orderId` đều có thể đọc thông tin đơn hàng mà không cần đăng nhập.

## Evidence
```bash
# Tạo đơn hàng bằng token hợp lệ
curl -X POST http://127.0.0.1:3000/api/checkout \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." \
  -H "X-Student-Id: 23127300" \
  -d '{"total_amount":200000,"shipping_address":"123 Test St"}'

Phản hồi: {"message":"Checkout successful","orderId":2}

# Đọc đơn hàng không có Authorization header
curl -X GET http://127.0.0.1:3000/api/orders/2 \
  -H "X-Student-Id: 23127300"

Phản hồi: 200 OK
{
  "id": 2,
  "user_id": 5,
  "total_amount": 200000,
  "status": "pending",
  "shipping_address": "123 Test St",
  "created_at": "2026-08-20 12:15:15"
}
```

Kẻ tấn công có thể thử lần lượt các `orderId` như `1`, `2`, `3`, ... để thu thập thông tin đơn hàng của nhiều người dùng mà không cần đăng nhập.
