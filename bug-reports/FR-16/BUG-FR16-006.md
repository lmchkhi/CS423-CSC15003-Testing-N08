## Found by Test Case

TC-FR16-UC-009

## Requirement liên quan

FR-16

## Severity / Priority

Major / P2

## Environment

Google Chrome, NodeJS Backend, SQLite

## Steps to reproduce

1. Chuẩn bị file CSV chứa sản phẩm có tên bắt đầu bằng ký tự đặc biệt của công thức bảng tính (ví dụ: `=cmd|' /C calc'!A0`).
2. Thực hiện Import file CSV vào hệ thống.

## Expected result

Hệ thống phát hiện ký tự đầu độc hại và từ chối chèn, hoặc thực hiện escape bằng cách thêm dấu nháy đơn `'` ở trước ký tự `=`.

## Actual result

Hệ thống lưu nguyên văn chuỗi `=cmd|' /C calc'!A0` vào cơ sở dữ liệu mà không xử lý hay escape, dẫn đến rủi ro thực thi lệnh khi quản trị viên xuất/tải file báo cáo CSV sau này và mở trên Excel.
