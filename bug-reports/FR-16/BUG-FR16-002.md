## Found by Test Case

TC-FR16-UC-003

## Requirement liên quan

FR-16

## Severity / Priority

Minor / P2

## Environment

Google Chrome, Windows 11, URL: http://localhost:5174

## Steps to reproduce

1. Mở tính năng Import sản phẩm từ CSV trên trang Admin.
2. Chọn tải lên file có đuôi khác `.csv` (ví dụ file `products.txt` hoặc `products.xlsx`).
3. Bấm tải lên/Import.

## Expected result

Hệ thống kiểm tra đuôi file và từ chối xử lý, hiển thị thông báo lỗi "Định dạng file không được hỗ trợ. Vui lòng chọn file .csv".

## Actual result

Hệ thống không kiểm tra đuôi file ở cả frontend và backend. File `.txt` hoặc bất kỳ file nào vẫn được đọc bằng `readAsText` và cố gắng gửi dữ liệu parse lỗi lên backend.
