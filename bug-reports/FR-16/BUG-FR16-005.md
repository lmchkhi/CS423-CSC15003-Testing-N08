## Found by Test Case

TC-FR16-UC-007

## Requirement liên quan

FR-16

## Severity / Priority

Critical / P0

## Environment

NodeJS Backend, SQLite, URL: http://localhost:3000

## Steps to reproduce

1. Chuẩn bị file CSV gồm 3 dòng: 2 dòng đầu thông tin hợp lệ, dòng 3 bị rỗng cột `name` (dòng lỗi).
2. Đăng nhập admin và bấm Import file này.

## Expected result

Hệ thống phát hiện lỗi ở dòng thứ 3, thực hiện rollback toàn bộ giao dịch. Không có bất kỳ sản phẩm nào từ file CSV được lưu vào DB (All-or-nothing).

## Actual result

Backend thực hiện câu lệnh chèn không đồng bộ bằng `stmt.run()` riêng lẻ không bọc trong Transaction. Hệ thống chèn thành công 2 dòng đầu vào CSDL SQLite và chỉ bỏ qua dòng thứ 3 bị lỗi.
