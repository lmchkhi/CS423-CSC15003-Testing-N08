# BUG-FR-07-014: Giao diện giỏ hàng thiếu nút giảm (-) để kiểm thử biên giá trị số lượng = 0 (BVA)

## Found by Test Case
TC-FR-07-016

## Requirement liên quan
FR-07: Giỏ hàng (Shopping Cart)

## Related Github issue
Issue #_

## Severity / Priority
Medium / P2

## Environment
- **Browser**: Zen Browser 1.21.3b (Firefox 152.0.1)
- **OS**: Fedora 44
- **URL**: http://localhost:5173

## Steps to reproduce
1. Mở trang Giỏ hàng (sau khi thêm sản phẩm với số lượng = 1)
2. Thử giảm số lượng xuống 0 bằng cách bấm nút `-`
3. Quan sát kết quả xem số lượng có xuống 0 được không

## Expected result
Hệ thống **không cho phép** số lượng = 0. Nút `-` bị vô hiệu hóa khi số lượng = 1, hoặc hiển thị cảnh báo/dialog xác nhận xóa sản phẩm.

## Actual result
Không có nút `-` hiển thị để thực hiện thao tác giảm số lượng, dẫn đến việc không thể kiểm thử hành vi hệ thống với giá trị số lượng không hợp lệ = 0.
