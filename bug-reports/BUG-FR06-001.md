# BUG-FR06-001: Product detail returns inconsistent JSON types for price

## Found by Test Case
OR-3 — `perf/scripts/smoke-oracle.sh`, transcript `perf/evidence/smoke-oracle-20260813-230513.txt`

## Requirement liên quan
FR-06 / `GET /api/products/:id`. `api_specification.md` không ghi response schema riêng cho product detail, nhưng phần product create/update mô tả `price` là số JSON (`"price": 100000`). Cùng một field `price` nên có kiểu nhất quán giữa các sản phẩm.

## Severity / Priority
Minor / P2

## Environment
**Tool**: cURL black-box oracle  
**OS / Hardware**: macOS 26.5.2, Apple M4 Pro 12-core, 24 GB RAM  
**SUT**: EShop backend API, `http://localhost:3000`  
**Date observed**: 2026-08-13 23:05:13 +07:00

## Steps to reproduce
1. Gửi `GET /api/products/1`.
2. Gửi `GET /api/products/2`.
3. So sánh kiểu JSON của trường `price`.
4. Lặp lại với id 3, 4, 5 để xác nhận pattern.

## Expected result
`price` phải luôn trả về cùng một kiểu JSON cho mọi sản phẩm, tốt nhất là number như tài liệu API đang mô tả ở payload sản phẩm.

## Actual result
Các id lẻ trả `price` là number, còn các id chẵn trả `price` là string. Client phải xử lý hai kiểu dữ liệu cho cùng một field.
