# BUG-FR-16-009: Báo cáo kết quả hiển thị thiếu thông tin lỗi và không rollback toàn bộ khi file CSV chứa nhiều dòng lỗi

## Found by Test Case
TC-FR-16-012

## Requirement liên quan
FR-16: Import Sản phẩm từ CSV

## Related Github issue
Issue #_

## Severity / Priority
High / P2

## Environment
- **Browser**: Zen Browser 1.21.3b (Firefox 152.0.1)
- **OS**: Fedora 44
- **URL**: http://localhost:5174/

## Steps to reproduce
1. Đăng nhập vào hệ thống với tài khoản Admin.
2. Truy cập trang Import sản phẩm từ CSV.
3. Chọn file `products_mixed.csv` (dòng 3 lỗi name rỗng, dòng 4 lỗi price là số âm) để tải lên.
4. Bấm nút Import.
5. Quan sát báo cáo kết quả và danh sách sản phẩm trong cơ sở dữ liệu.

## Expected result
Hệ thống hiển thị báo cáo rõ ràng gồm: số dòng thành công (1), số dòng lỗi (2), và lý do cụ thể cho mỗi dòng lỗi (dòng 3: name không được rỗng; dòng 4: price phải là số dương). Toàn bộ import bị rollback do có lỗi (không có sản phẩm nào được import).

## Actual result
Hệ thống chỉ báo lỗi ở dòng 3 (thiếu tên sản phẩm), không báo lỗi ở dòng 4 (giá âm) và vẫn cho phép import 2 sản phẩm còn lại (không thực hiện rollback toàn bộ).
