# BUG-FR-16-009: Hệ thống không rollback toàn bộ giao dịch khi file CSV có 1 dòng dữ liệu bị lỗi

## Found by Test Case
TC-FR-16-011

## Requirement liên quan
FR-16: Import Sản phẩm từ CSV

## Related Github issue
Issue #_

## Severity / Priority
High / P2

## Environment
- **Browser**: Zen Browser 1.21.3b (Firefox 152.0.1)
- **OS**: Fedora 44
- **URL**: http://localhost:5174/

## Steps to reproduce
1. Đăng nhập vào hệ thống với tài khoản Admin.
2. Ghi nhận số lượng sản phẩm hiện tại.
3. Chọn file `products_rollback.csv` (dòng 3 có `name` bị rỗng là dữ liệu lỗi) để tải lên.
4. Bấm nút Import.
5. Kiểm tra lại danh sách hoặc số lượng sản phẩm.

## Expected result
Import thất bại. Toàn bộ giao dịch bị rollback (all-or-nothing). Không có sản phẩm mới nào được thêm vào hệ thống (các dòng hợp lệ như dòng 2 và 4 cũng không được lưu). Số lượng sản phẩm giữ nguyên như trước khi import.

## Actual result
Hệ thống không thực hiện rollback toàn bộ, vẫn import thành công các sản phẩm ở các dòng hợp lệ còn lại (dòng 2 và dòng 4) vào cơ sở dữ liệu.
