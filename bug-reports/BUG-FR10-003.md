# BUG-FR10-003: User thường gọi được API Admin để cập nhật trạng thái đơn hàng

## Found by Test Case
TC-FR10-DT-011

## Requirement liên quan
FR-10, FR-12

## Severity / Priority
Critical / P1

Lý do: Lỗi kiểm soát quyền trên API Admin cho phép User thường thay đổi trạng thái đơn hàng của bất kỳ ai, gây rủi ro bảo mật và toàn vẹn dữ liệu nghiêm trọng.

## Environment
**Browser**: Chrome Version 149.0.7827.103
**OS**: macOS Tahoe 26.5.1
**URL**: Backend `http://localhost:3000`; Frontend Admin `http://localhost:5174/`; Frontend Web `http://localhost:5173/`
**Build / Commit**: `31a3053`

## Steps to reproduce
1. Đăng nhập Frontend Web bằng tài khoản User thường.
2. Mở DevTools trên trình duyệt.
3. Gọi endpoint cập nhật trạng thái đơn hàng dành cho Admin:

```js
fetch("http://localhost:3000/api/admin/orders/4/status", {
  method: "PUT",
  headers: {
    "Content-Type": "application/json",
    "Authorization": "Bearer " + localStorage.getItem("token")
  },
  body: JSON.stringify({
    status: "confirmed"
  })
}).then(r => r.json()).then(console.log)
```

4. Quan sát response của API và trạng thái đơn hàng.

## Expected result
Hệ thống từ chối thao tác, hiển thị lỗi phù hợp vì xác nhận đơn hàng là thao tác của Admin, và trạng thái của `ORDER-FR10-011` vẫn là `pending`.

Theo FR-12, tất cả API Admin `/api/admin/*` phải yêu cầu token JWT hợp lệ và `role = 'admin'` trong token.

## Actual result
Endpoint cập nhật trạng thái đơn hàng `PUT /api/admin/orders/:id/status` không kiểm tra quyền Admin. Dù là User thường, chỉ cần lấy token gọi API qua DevTools là có thể tự do thay đổi trạng thái đơn hàng của bất kỳ ai. API trả về HTTP 200 thành công với message `"Order status updated"`.
