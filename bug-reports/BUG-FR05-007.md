## Found by Test Case

TC-FR05-DT-011

## Requirement liên quan

FR-05, FR-21

## Severity / Priority

Trivial / P3

## Environment

- Browser: Chrome (latest)
- OS: Windows
- Frontend: http://localhost:5173
- Backend: http://localhost:3000

## Steps to reproduce

1. Mở trình duyệt, truy cập http://localhost:5173
2. Chờ trang tải hoàn tất
3. Mở DevTools (F12) → tab Console
4. Nhập lệnh: `document.querySelectorAll('h1').length` và nhấn Enter
5. Quan sát kết quả trả về

## Expected result

Kết quả trả về là `1` — trang chủ chỉ chứa đúng 1 thẻ `<h1>` mô tả nội dung trang

## Actual result

Kết quả trả về là `2` — trang chủ chứa 2 thẻ `<h1>`. Vi phạm tiêu chuẩn SEO và accessibility, đồng thời vi phạm yêu cầu đặc tả FR-05 và FR-21.
