# [BUG][FR-01 Register] No input validation — empty and weak passwords accepted

## Found by Test Case
FR-01 Register API test case — các vòng lặp dữ liệu phát hiện thiếu kiểm tra độ mạnh mật khẩu

## Requirement liên quan
FR-01 Register: Mật khẩu phải đạt yêu cầu tối thiểu về độ dài và độ phức tạp.

## Severity / Priority
Major / P1

## Environment
**Tool**: Postman collection v2.1 / Newman headless
**Collection**: `api/collections/eshop-hw06.postman_collection.json`
**Environment file**: `api/environments/local.postman_environment.json` (`baseUrl = http://localhost:3000`)
**Observed request host**: `http://127.0.0.1:3000` trong collection/Newman logs
**Folder / data / report**: `FR-01 Register`, `api/data/register-cases.json`, `api/newman/fr01-register-report.html`
**Anti-cheat header**: `X-Student-Id: 23127300`
**OS / Hardware / build**: Không được ghi nhận trong Newman artifact nộp; không dùng làm bằng chứng cho bug này.

## Steps to reproduce
1. Gửi `POST /api/register` với `{"name":"User","email":"empty@test.com","password":""}`.
2. Quan sát hệ thống trả `200 OK`.
3. Gửi `POST /api/register` với `{"name":"User","email":"weak@test.com","password":"123"}`.
4. Quan sát hệ thống tiếp tục trả `200 OK`.

## Expected result
Cả hai yêu cầu phải bị từ chối với `400 Bad Request`, kèm thông báo nêu rõ yêu cầu mật khẩu, ví dụ tối thiểu 8 ký tự và có chữ hoa, chữ thường, số, ký tự đặc biệt.

## Actual result
Hệ thống chấp nhận cả mật khẩu rỗng và mật khẩu yếu `"123"`. Phản hồi lần lượt là `{"message":"User registered successfully","id":103}` và `{"message":"User registered successfully","id":104}` với HTTP `200 OK`.

## Evidence
```bash
curl -X POST http://127.0.0.1:3000/api/register \
  -H "Content-Type: application/json" \
  -H "X-Student-Id: 23127300" \
  -d '{"name":"Test User","email":"weak@test.com","password":""}'

Phản hồi: {"message":"User registered successfully","id":103}

curl -X POST http://127.0.0.1:3000/api/register \
  -H "Content-Type: application/json" \
  -H "X-Student-Id: 23127300" \
  -d '{"name":"Test User","email":"weak2@test.com","password":"123"}'

Phản hồi: {"message":"User registered successfully","id":104}
```

Dữ liệu từ Newman: các vòng lặp `EX-002 empty body NULLs`, `EX-004 weak password 123` và `EX-005 whitespace only email` đều mong đợi `400`, nhưng SUT trả `200`.
