# BUG-FR-16-001: Hệ thống vẫn cho phép import sản phẩm thành công khi tải lên file .txt không phải đuôi .csv

## Found by Test Case
TC-FR-16-002

## Requirement liên quan
FR-16: Import Sản phẩm từ CSV

## Related Github issue
Issue #24

## Severity / Priority
Medium / P3

## Environment
- **Browser**: Zen Browser 1.21.3b (Firefox 152.0.1)
- **OS**: Fedora 44
- **URL**: http://localhost:5174

## Steps to reproduce
1. Đăng nhập vào hệ thống với tài khoản Admin.
2. Truy cập trang Import sản phẩm từ CSV.
3. Chọn file `products.txt` (nội dung là dữ liệu CSV hợp lệ nhưng đuôi file là `.txt`) để tải lên.
4. Bấm nút Import.

## Expected result
Hệ thống từ chối file, hiển thị thông báo lỗi yêu cầu file phải có đuôi `.csv` và không thực hiện import sản phẩm vào hệ thống.

## Actual result
Hệ thống vẫn chấp nhận file `.txt`, tiến hành import sản phẩm thành công và không hiển thị bất kỳ thông báo lỗi nào.
