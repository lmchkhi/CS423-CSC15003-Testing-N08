## Found by Test Case

TC-FR12-DT-033, TC-FR12-DT-036, TC-FR12-DT-039

## Requirement liên quan

FR-12, SEC-03

## Severity / Priority

Critical / P0

## Environment

- API Tool: Postman / cURL
- OS: Windows
- Backend: http://localhost:3000

## Steps to reproduce

1. Gửi `POST http://localhost:3000/api/login` với body `{"email": "test@eshop.com", "password": "Test1234!"}` — đăng nhập bằng tài khoản user thường
2. Copy giá trị `token` từ response
3. Tạo request POST đến `http://localhost:3000/api/categories`
4. Thêm header `Authorization: Bearer <user_token>`
5. Thêm body JSON: `{"name": "Danh mục test AC"}`
6. Gửi request
7. Quan sát response

## Expected result

Hệ thống trả về HTTP 403 Forbidden. Theo FR-12: các API có tính ảnh hưởng dữ liệu (`POST/PUT/DELETE /api/categories`) phải yêu cầu `role = 'admin'`. User thường không được phép tạo/sửa/xóa danh mục.

## Actual result

Hệ thống trả về HTTP 200 OK. Danh mục mới được tạo thành công bởi user thường. Các endpoint `POST /api/categories`, `PUT /api/categories/:id` và `DELETE /api/categories/:id` có kiểm tra Token (no token → 401) nhưng KHÔNG kiểm tra role — user thường có thể thao tác dữ liệu danh mục.
