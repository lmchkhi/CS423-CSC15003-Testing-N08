## Found by Test Case

TC-FR12-DT-003, TC-FR12-DT-006, TC-FR12-DT-009, TC-FR12-DT-012, TC-FR12-DT-015, TC-FR12-DT-018, TC-FR12-DT-021

## Requirement liên quan

FR-12, SEC-03

## Severity / Priority

Critical / P0

## Environment

- API Tool: Postman / cURL
- OS: Windows
- Backend: http://localhost:3000

## Steps to reproduce

1. Gửi `POST http://localhost:3000/api/login` với body `{"email": "test@eshop.com", "password": "Test1234!"}` — đăng nhập bằng tài khoản user thường (role = 'user')
2. Copy giá trị `token` từ response
3. Tạo request GET đến `http://localhost:3000/api/admin/users`
4. Thêm header `Authorization: Bearer <user_token>`
5. Gửi request
6. Quan sát response

## Expected result

Hệ thống trả về HTTP 403 Forbidden. Theo FR-12 và SEC-03: "API Admin phải kiểm tra `role = 'admin'` trong Token, không chỉ kiểm tra sự tồn tại của Token". User thường không được phép truy cập Admin API.

## Actual result

Hệ thống trả về HTTP 200 OK và trả về danh sách toàn bộ người dùng. Lỗi này xảy ra trên TẤT CẢ các Admin API endpoints (`/api/admin/*`): GET users, DELETE users, GET orders, PUT orders status, POST import-products, POST coupons, DELETE coupons. Middleware chỉ kiểm tra sự tồn tại của Token mà KHÔNG kiểm tra giá trị role — vi phạm trực tiếp SEC-03.
