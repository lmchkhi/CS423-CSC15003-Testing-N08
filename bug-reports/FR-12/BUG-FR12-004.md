## Found by Test Case

TC-FR12-DT-002

## Requirement liên quan

FR-12, SEC-02

## Severity / Priority

Minor / P2

## Environment

- API Tool: Postman / cURL
- OS: Windows
- Backend: http://localhost:3000

## Steps to reproduce

1. Mở công cụ API testing (Postman hoặc cURL)
2. Tạo request GET đến `http://localhost:3000/api/admin/users`
3. Thêm header `Authorization: Bearer invalid_token_xyz123`
4. Gửi request
5. Quan sát response

## Expected result

Hệ thống trả về HTTP 401 Unauthorized. Token không hợp lệ/giả mạo nên bị từ chối ở bước xác thực (authentication), trước khi đến bước phân quyền (authorization).

## Actual result

Hệ thống trả về HTTP 403 Forbidden thay vì 401 Unauthorized. Mặc dù request bị từ chối (đúng), mã lỗi HTTP không chính xác — 403 Forbidden thường dùng cho trường hợp đã xác thực nhưng không đủ quyền, trong khi 401 Unauthorized dùng cho trường hợp chưa xác thực hoặc token không hợp lệ.
