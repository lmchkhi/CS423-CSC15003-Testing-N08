## Found by Test Case

TC-FR05-DT-006

## Requirement liên quan

FR-05, SEC-04

## Severity / Priority

Critical / P0

## Environment

- Browser: Chrome (latest)
- OS: Windows
- Frontend: http://localhost:5173
- Backend: http://localhost:3000

## Steps to reproduce

1. Mở trình duyệt, truy cập http://localhost:5173
2. Mở DevTools (F12) → tab Console
3. Nhập `<script>alert('XSS')</script>` vào thanh tìm kiếm
4. Nhấn Enter hoặc nút tìm kiếm
5. Quan sát phản hồi từ hệ thống và tab Console/Network

## Expected result

Hệ thống hiển thị chuỗi XSS dưới dạng plain text (escaped), không render HTML/JS, không có alert popup, không lỗi server

## Actual result

Server trả về HTTP 500 Internal Server Error. UI hiển thị raw database error: "Database Error - SQLITE_ERROR: near "XSS": syntax error". Lỗi này cho thấy input không được sanitize trước khi truyền vào câu truy vấn SQL, vi phạm SEC-04 và SEC-05.
