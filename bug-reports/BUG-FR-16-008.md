# BUG-FR-16-008: Hệ thống parse sai trường description có chứa dấu phẩy bọc trong dấu nháy kép

## Found by Test Case
TC-FR-16-010

## Requirement liên quan
FR-16: Import Sản phẩm từ CSV

## Related Github issue
Issue #31

## Severity / Priority
Medium / P3

## Environment
- **Browser**: Zen Browser 1.21.3b (Firefox 152.0.1)
- **OS**: Fedora 44
- **URL**: http://localhost:5174/

## Steps to reproduce
1. Đăng nhập vào hệ thống với tài khoản Admin.
2. Truy cập trang Import sản phẩm từ CSV.
3. Chọn file `products_comma_in_field.csv` (các trường chứa dấu phẩy được bọc trong dấu nháy kép như `"Màn hình 15.6 inch, Full HD, RAM 16GB"`) để tải lên.
4. Bấm nút Import.

## Expected result
Import thành công. Hệ thống parse đúng trường `description` chứa dấu phẩy (không bị tách cột sai). 2 sản phẩm được lưu với mô tả đầy đủ. Báo cáo hiển thị: 2 dòng thành công, 0 dòng lỗi.

## Actual result
Hệ thống parse sai trường `description` có chứa dấu phẩy bọc trong nháy kép, dẫn đến việc tách cột sai hoặc lệch trường thông tin sản phẩm.
