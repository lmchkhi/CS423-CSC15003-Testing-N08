# BUG-FR10-001: Đơn hàng đã hủy vẫn có thể bị chuyển sang đã giao

## Found by Test Case
TC-FR10-DT-009

## Requirement liên quan
FR-10

## Severity / Priority
High / P2

Lý do: Lỗi vi phạm final state của state machine, làm sai dữ liệu vòng đời đơn hàng khi đơn `canceled` bị chuyển thành `delivered`.

## Environment
**Browser**: Chrome Version 149.0.7827.103
**OS**: macOS Tahoe 26.5.1
**URL**: Backend `http://localhost:3000`; Frontend Admin `http://localhost:5174/`; Frontend Web `http://localhost:5173/`
**Build / Commit**: `31a3053`

## Steps to reproduce
1. Đăng nhập Frontend Admin bằng tài khoản Admin.
2. Mở màn hình **Đơn hàng** tại Frontend Admin.
3. Quan sát đơn hàng đang ở trạng thái **Đã hủy**.
4. Bấm nút **Đánh dấu Đã giao** trên dòng đơn hàng đã hủy.
5. Quan sát trạng thái đơn hàng sau thao tác.

## Expected result
Hệ thống từ chối thao tác, hiển thị lỗi phù hợp vì `canceled` là trạng thái kết thúc, và trạng thái của `ORDER-FR10-009` vẫn là `canceled`.

## Actual result
Đơn hàng đã ở trạng thái kết thúc `canceled` (**Đã hủy**) nhưng UI vẫn hiện nút **Đánh dấu Đã giao**. Khi click vào nút này, hệ thống báo thao tác thành công và đơn hàng bị chuyển sang trạng thái `delivered` (**Đã giao**).

Backend chặn đúng các chuyển đổi trạng thái khác nhưng lại để lọt trường hợp chuyển từ `canceled` sang `delivered`.
