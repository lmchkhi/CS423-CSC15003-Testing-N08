## Found by Test Case

TC-FR09-STT-018

## Requirement liên quan

FR-09 (Mã Giảm Giá - Coupon) - Điều kiện C2 (Còn hạn sử dụng)

## Severity / Priority

Major / P1

## Environment

Web Frontend (localhost:5173), Backend API (localhost:3000)

## Steps to reproduce

1. Đăng nhập với tài khoản hợp lệ (`test@eshop.com`).
2. Thêm sản phẩm vào giỏ hàng sao cho tổng tiền >= 100,000đ.
3. Vào trang Checkout (S0: Idle).
4. Nhập mã `EXPIRED` (mã có `is_active=1` nhưng `expired_at` là `2020-01-01`, tức là đã qua).
5. Bấm "Áp dụng".

## Expected result

Hệ thống phải kiểm tra độc lập điều kiện C2 (thời gian hiện tại phải nhỏ hơn `expired_at`).
Hệ thống chuyển sang trạng thái Rejected (S3) và hiển thị thông báo lỗi: "Mã đã hết hạn".

## Actual result

Hệ thống chấp nhận mã `EXPIRED`, chuyển sang trạng thái Applied (S2) và tiến hành giảm 20% cho đơn hàng.
Backend dường như chỉ kiểm tra cờ `is_active = 1` (C1) mà bỏ qua việc so sánh ngày tháng (C2).
