# BUG-FR02-004: Frontend không hiển thị thông báo tài khoản bị khóa từ backend

## Found by Test Case
[TC-FR02-DT-006](../tests/test-cases/FR-02-login/domain-testing/TC-FR02-DT-006.md)

## Requirement liên quan
FR-02

## Severity / Priority
Low / P3

Severity Low vì lỗi chủ yếu ảnh hưởng đến thông báo trên giao diện, không làm thay đổi trạng thái khóa hoặc cấp token. Priority P3 vì có thể sửa sau các lỗi chặn đăng nhập và lỗi bảo mật nghiêm trọng hơn.

## Environment
**Browser**: Chrome Version 149.0.7827.103  
**OS**: macOS Tahoe 26.5.1  
**Backend URL**: `http://localhost:3000`  
**Frontend Web URL**: `http://localhost:5173/`  
**Build / Commit**: `a172955`

## Steps to reproduce
1. Tạo trạng thái tài khoản bị khóa cho `test@eshop.com` bằng các lần đăng nhập sai liên tiếp.
2. Trong khi tài khoản vẫn đang bị tạm khóa, nhập `test@eshop.com` vào trường Email.
3. Nhập mật khẩu đúng `Test1234!`.
4. Thực hiện đăng nhập.
5. Quan sát thông báo trên frontend và response API trong DevTools/Network.

## Expected result
Đăng nhập bị từ chối vì tài khoản đang trong 30 giây tạm khóa. Hệ thống hiện thông báo lỗi phù hợp, không tạo token mới và người dùng vẫn ở trạng thái chưa đăng nhập.

## Actual result
Khi tài khoản bị khóa, giao diện chỉ báo lỗi chung chung là `Đăng nhập thất bại`. Kiểm tra API thấy backend có trả về dòng `Tài khoản đã bị khóa` nhưng frontend không hiển thị lên cho người dùng thấy.
