# BUG-FR06-002: Nonexistent product detail returns HTTP 200 with an empty object

## Found by Test Case
OR-4 — `perf/scripts/smoke-oracle.sh`, transcript `perf/evidence/smoke-oracle-20260813-230513.txt`

## Requirement liên quan
FR-06 / `GET /api/products/:id`. API chi tiết sản phẩm dùng path id để lấy một tài nguyên cụ thể; khi tài nguyên không tồn tại, response nên báo not found thay vì thành công rỗng.

## Severity / Priority
Minor / P2

## Environment
**Tool**: cURL black-box oracle  
**OS / Hardware**: macOS 26.5.2, Apple M4 Pro 12-core, 24 GB RAM  
**SUT**: EShop backend API, `http://localhost:3000`  
**Date observed**: 2026-08-13 23:05:13 +07:00

## Steps to reproduce
1. Đảm bảo SUT đang chạy ở `http://localhost:3000`.
2. Gửi request `GET /api/products/999999` hoặc một id không có trong catalogue.
3. Quan sát HTTP status code và body.

## Expected result
API trả HTTP 404 hoặc một lỗi tương đương để client biết sản phẩm không tồn tại.

## Actual result
API trả HTTP 200 với body `{}`. Response này làm client/test tự hiểu nhầm đây là request thành công.

`http://localhost:3000`; script chỉ dùng HTTP request và không trích dẫn source
code của SUT. Chạy lại bằng:
