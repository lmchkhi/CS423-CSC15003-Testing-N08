# BUG-FR-07-009: Thiếu dialog xác nhận xóa sản phẩm khi thực hiện kiểm thử hủy xóa sản phẩm

## Found by Test Case
TC-FR-07-009

## Requirement liên quan
FR-07: Giỏ hàng (Shopping Cart)

## Related Github issue
Issue #_

## Severity / Priority
Medium / P2

## Environment
- **Browser**: Zen Browser 1.21.3b (Firefox 152.0.1)
- **OS**: Fedora 44
- **URL**: http://localhost:5173

## Steps to reproduce
1. Mở trang Giỏ hàng (đã có sản phẩm "iPhone 15 Pro Max")
2. Bấm nút `Xóa` ở cột "Thao tác"
3. Chờ dialog xác nhận xuất hiện
4. Bấm nút hủy (ví dụ: "Hủy" / "Không") trên dialog

## Expected result
Sản phẩm **vẫn còn trong giỏ hàng** với số lượng và thành tiền không thay đổi sau khi chọn hủy xóa. Dialog xác nhận đóng lại.

## Actual result
Hệ thống không hiển thị dialog xác nhận nên không thể thực hiện bước hủy xóa sản phẩm theo các bước kiểm thử. Sản phẩm bị xóa ngay lập tức khi bấm nút `Xóa` ở bước 2.
