# BUG-FR02-001: Login account lockout is observable but undocumented

## Found by Test Case
OR-2 — `perf/scripts/smoke-oracle.sh`, transcript `perf/evidence/smoke-oracle-20260813-230513.txt`

## Requirement liên quan
FR-02 / `POST /api/login` trong `api_specification.md` chỉ tài liệu hoá phản hồi thành công 200 với JWT; không mô tả ngưỡng khoá, HTTP 403, hoặc thời gian tự mở khoá.

## Severity / Priority
Major / P1

## Environment
**Tool**: cURL black-box oracle, Apache JMeter evidence set  
**OS / Hardware**: macOS 26.5.2, Apple M4 Pro 12-core, 24 GB RAM  
**SUT**: EShop backend API, `http://localhost:3000`  
**Date observed**: 2026-08-13 23:05:13 +07:00

## Steps to reproduce
1. Đăng ký một tài khoản mới qua `POST /api/register`.
2. Gửi `POST /api/login` với đúng email nhưng sai password hai lần liên tiếp.
3. Gửi `POST /api/login` với đúng email và đúng password.
4. Tiếp tục thử lại mỗi 15 giây cho tới khi đăng nhập thành công.

## Expected result
Tài liệu API phải mô tả đầy đủ hành vi khoá tài khoản: ngưỡng bao nhiêu lần sai, response code/body khi bị khoá, và thời gian tự mở khoá. Nếu hành vi chưa được tài liệu hoá, client/tester không nên gặp một HTTP 403 không có trong hợp đồng API.

## Actual result
Sau hai lần sai, lần đăng nhập đúng password vẫn trả HTTP 403 với body `{"error":"Tài khoản đã bị khóa. Vui lòng thử lại sau."}`. Tài khoản tự mở sau khoảng 180 giây.

## Evidence
Trích từ `perf/evidence/smoke-oracle-20260813-230513.txt`:

```text
failed attempt 1 -> HTTP 401 {"error":"Invalid email or password"}
failed attempt 2 -> HTTP 401 {"error":"Invalid email or password"}
failed attempt 3 -> HTTP 403 {"error":"Tài khoản đã bị khóa. Vui lòng thử lại sau."}
correct password now -> HTTP 403 {"error":"Tài khoản đã bị khóa. Vui lòng thử lại sau."}
t+180s -> HTTP 200
```
