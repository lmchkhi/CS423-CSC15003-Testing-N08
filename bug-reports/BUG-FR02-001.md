# BUG-FR02-001: API đăng nhập trả về mật khẩu người dùng ở dạng không mã hóa

## Found by Test Case
[TC-FR02-DT-001](../tests/test-cases/FR-02-login/domain-testing/TC-FR02-DT-001.md)

## Requirement liên quan
FR-02

## Severity / Priority
Critical / P1

Severity Critical vì response đăng nhập làm lộ `password` dạng không mã hóa và các trường ẩn khác, tạo rủi ro bảo mật nghiêm trọng. Priority P1 vì cần xử lý trước khi tiếp tục release/test bảo mật luồng xác thực.

## Environment
**Browser**: Chrome Version 149.0.7827.103  
**OS**: macOS Tahoe 26.5.1  
**Backend URL**: `http://localhost:3000`  
**Frontend Web URL**: `http://localhost:5173/`  

## Steps to reproduce
1. Mở màn hình Đăng nhập trên Frontend Web `http://localhost:5173/`.
2. Nhập email `test@eshop.com`.
3. Nhập mật khẩu `Test1234!`.
4. Thực hiện đăng nhập.
5. Quan sát response API đăng nhập trong DevTools/Network.

## Expected result
Đăng nhập được chấp nhận. Người dùng được đưa vào trạng thái đã đăng nhập, token được lưu phía client, và người dùng truy cập được chức năng yêu cầu xác thực. Không hiện thông báo lỗi đăng nhập. Response không được trả về mật khẩu người dùng ở dạng không mã hóa hoặc các trường ẩn không cần thiết.

## Actual result
Sau khi đăng nhập thành công, API trả về toàn bộ dữ liệu user bao gồm cả mật khẩu (`password`) ở dạng không mã hóa và các trường ẩn khác. Việc này làm lộ mật khẩu trong response của API.
