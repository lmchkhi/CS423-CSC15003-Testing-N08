## Found by Test Case

TC-FR05-DT-004

## Requirement liên quan

FR-05

## Severity / Priority

Minor / P2

## Environment

- Browser: Chrome (latest)
- OS: Windows
- Frontend: http://localhost:5173
- Backend: http://localhost:3000

## Steps to reproduce

1. Mở trình duyệt, truy cập http://localhost:5173
2. Nhập từ khóa "Áo @#$%" vào thanh tìm kiếm
3. Nhấn Enter hoặc nút tìm kiếm
4. Quan sát khu vực hiển thị kết quả

## Expected result

Hệ thống xử lý an toàn, hiển thị kết quả tìm kiếm phù hợp hoặc empty state nếu không có kết quả khớp

## Actual result

Hệ thống không trả về kết quả tìm kiếm và cũng không hiển thị empty state. Khu vực danh sách sản phẩm trống.
