# BUG-FR02-003: Email sai định dạng vẫn gọi API login thay vì bị HTML5 validation chặn

## Found by Test Case
TC-FR02-ST-007

## Requirement liên quan
FR-02: Đăng nhập & Khóa tài khoản

## Severity / Priority
Minor / P2

## Environment
**Browser**: Chrome 1xx  
**OS**: Ubuntu 22.04  
**Frontend URL**: http://localhost:5173  
**API URL**: http://localhost:3000  
**Build / Commit**: `29da7b0`

## Steps to reproduce
1. Mở màn hình Đăng nhập trên Web.
2. Nhập email sai định dạng, ví dụ `invalid-email`.
3. Nhập password bất kỳ, ví dụ `WrongPassword123!`.
4. Bấm nút Đăng nhập.
5. Quan sát HTML5 validation và network/API request.

## Expected result
Theo FR-02, trường email phải dùng `type="email"` và có validate HTML5 format. Với email sai định dạng, browser/UI phải chặn submit trước khi gọi `POST /api/login`; không nên gửi request login và không nên tăng failed-login counter.

## Actual result
UI vẫn gọi API login với email sai định dạng. API trả lỗi `Invalid email or password` thay vì form bị chặn bởi HTML5 email validation trước khi submit.

## Evidence
- Tester observation ở `TC-FR02-ST-007`: email sai định dạng vẫn gọi API login và trả lỗi `Invalid email or password`.
