# BUG-FR10-002: User vẫn hủy được đơn hàng đang giao

## Found by Test Case
TC-FR10-DT-010

## Requirement liên quan
FR-10

## Severity / Priority
High / P2

Lý do: Lỗi cho phép User thực hiện thao tác bị cấm theo state machine, làm thay đổi trạng thái đơn hàng đang giao sang `canceled`.

## Environment
**Browser**: Chrome Version 149.0.7827.103
**OS**: macOS Tahoe 26.5.1
**URL**: Backend `http://localhost:3000`; Frontend Admin `http://localhost:5174/`; Frontend Web `http://localhost:5173/`

## Steps to reproduce
1. Đăng nhập Frontend Web bằng tài khoản User sở hữu đơn hàng.
2. Mở trang hồ sơ hoặc lịch sử đơn hàng tại Frontend Web.
3. Quan sát đơn hàng đang ở trạng thái **Đang giao**.
4. Bấm nút **Hủy đơn** trên dòng đơn hàng đang giao.
5. Quan sát phản hồi API và trạng thái đơn hàng sau thao tác.

## Expected result
Hệ thống từ chối thao tác hủy, hiển thị lỗi phù hợp vì User không được tự hủy đơn hàng ở trạng thái `shipping`, và trạng thái của `ORDER-FR10-010` vẫn là `shipping`.

## Actual result
Đơn hàng đang ở trạng thái `shipping` (**Đang giao**) nhưng giao diện vẫn hiển thị nút **Hủy đơn**. Khi User bấm vào, hệ thống vẫn cho phép hủy thành công, trả về message `"Order canceled successfully"` và đổi trạng thái đơn hàng sang `canceled` (**Đã hủy**).
