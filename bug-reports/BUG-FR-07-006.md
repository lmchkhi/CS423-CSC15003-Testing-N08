# BUG-FR-07-006: Giao diện giỏ hàng trống thiếu hình minh họa trực quan

## Found by Test Case
TC-FR-07-012

## Requirement liên quan
FR-07: Giỏ hàng (Shopping Cart)

## Related Github issue
Issue #23

## Severity / Priority
Low / P3

## Environment
- **Browser**: Zen Browser 1.21.3b (Firefox 152.0.1)
- **OS**: Fedora 44
- **URL**: http://localhost:5173

## Steps to reproduce
1. Đảm bảo giỏ hàng trống (xóa hết sản phẩm nếu có)
2. Mở trang Giỏ hàng tại http://localhost:5173
3. Quan sát giao diện giỏ hàng trống

## Expected result
Trang giỏ hàng trống hiển thị đầy đủ:
1. **Hình minh họa** (ví dụ: hình giỏ hàng trống, icon cart rỗng)
2. **Thông báo rõ ràng** (ví dụ: "Giỏ hàng của bạn đang trống")
3. Liên kết/nút **"Tiếp tục mua sắm"** để quay về trang chủ

## Actual result
Giao diện khi giỏ hàng trống chỉ hiển thị dòng thông báo bằng văn bản và nút "Tiếp tục mua sắm", hoàn toàn không hiển thị hình minh họa hay icon giỏ hàng rỗng.
