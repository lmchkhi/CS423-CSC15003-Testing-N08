# BUG-FR03-001: Password reset token is 4 digits while API documents a 6-digit token

## Found by Test Case
OR-1 — `perf/scripts/smoke-oracle.sh`, transcript `perf/evidence/smoke-oracle-20260813-230513.txt`

## Requirement liên quan
FR-03 / `POST /api/forgot-password` và `POST /api/reset-password` trong `api_specification.md` dùng ví dụ `resetToken: "123456"` ở cả phản hồi và request, thể hiện token 6 chữ số.

## Severity / Priority
Minor / P2

## Environment
**Tool**: cURL black-box oracle  
**OS / Hardware**: macOS 26.5.2, Apple M4 Pro 12-core, 24 GB RAM  
**SUT**: EShop backend API, `http://localhost:3000`  
**Date observed**: 2026-08-13 23:05:13 +07:00

## Steps to reproduce
1. Đăng ký một tài khoản mới qua `POST /api/register`.
2. Gửi `POST /api/forgot-password` với email vừa đăng ký.
3. Quan sát trường `resetToken` trong response.
4. Dùng token đó trong `POST /api/reset-password`.

## Expected result
`resetToken` nên khớp định dạng tài liệu API, tức 6 chữ số như ví dụ `"123456"`, hoặc tài liệu phải được sửa để nói rõ token thực tế là 4 chữ số.

## Actual result
Response trả token 4 chữ số, ví dụ `5621` và `9832`. Token 4 chữ số vẫn reset được mật khẩu, nên đây là lệch hợp đồng tài liệu chứ không phải lỗi luồng chức năng.

## Evidence
**Evidence type:** console log / black-box API transcript. This was captured by
running `perf/scripts/smoke-oracle.sh` against `http://localhost:3000`; the
script uses HTTP requests only and does not cite SUT source code. Re-run with:

```bash
bash perf/scripts/smoke-oracle.sh
```

```text

      token=5621

      token=9832
```

Trích từ `api_specification.md`:
