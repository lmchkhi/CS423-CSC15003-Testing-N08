# BUG-FR-16-011: Hệ thống cho phép import sản phẩm thành công khi price = 0 (phân tích giá trị biên)

## Found by Test Case
TC-FR-16-014

## Requirement liên quan
FR-16: Import Sản phẩm từ CSV

## Related Github issue
Issue #_

## Severity / Priority
High / P2

## Environment
- **Browser**: Zen Browser 1.21.3b (Firefox 152.0.1)
- **OS**: Fedora 44
- **URL**: http://localhost:5174/

## Steps to reproduce
1. Đăng nhập vào hệ thống với tài khoản Admin.
2. Truy cập trang Import sản phẩm từ CSV.
3. Chọn file `products_price_bva_off_minus.csv` (chứa sản phẩm có `price` = 0) để tải lên.
4. Bấm nút Import.

## Expected result
Import thất bại. Toàn bộ giao dịch bị rollback. Báo cáo hiển thị: 0 dòng thành công, 1 dòng lỗi (dòng 2: price phải là số dương).

## Actual result
Hệ thống import thành công sản phẩm có `price` = 0 và không hiển thị thông báo lỗi nào.
