# BUG-FR-16-002: Hệ thống vẫn cho phép import sản phẩm thành công khi file CSV có header sai (thiếu cột)

## Found by Test Case
TC-FR-16-004

## Requirement liên quan
FR-16: Import Sản phẩm từ CSV

## Related Github issue
Issue #25

## Severity / Priority
High / P2

## Environment
- **Browser**: Zen Browser 1.21.3b (Firefox 152.0.1)
- **OS**: Fedora 44
- **URL**: http://localhost:5174/

## Steps to reproduce
1. Đăng nhập vào hệ thống với tài khoản Admin.
2. Truy cập trang Import sản phẩm từ CSV.
3. Chọn file `products_bad_header.csv` (nội dung thiếu cột `imageUrl` và `category_id`) để tải lên.
4. Bấm nút Import.

## Expected result
Hệ thống từ chối file, hiển thị thông báo lỗi: header không đúng định dạng yêu cầu (`name,price,description,imageUrl,category_id`). Không thực hiện import.

## Actual result
Hệ thống vẫn cho import bình thường không báo lỗi.
