# BUG-FR-16-003: Hệ thống báo lỗi nhưng vẫn import các sản phẩm khác mà không thực hiện rollback toàn bộ khi file CSV có dòng lỗi tên rỗng

Issue #_

High / P2

## Environment
- **Browser**: Zen Browser 1.21.3b (Firefox 152.0.1)
- **OS**: Fedora 44
- **URL**: http://localhost:5174/

## Steps to reproduce
1. Đăng nhập vào hệ thống với tài khoản Admin.
2. Truy cập trang Import sản phẩm từ CSV.
3. Chọn file `products_empty_name.csv` (dòng 3 có cột `name` bị rỗng) để tải lên.
4. Bấm nút Import.

## Expected result
Import thất bại. Toàn bộ giao dịch bị rollback — không có sản phẩm nào được lưu. Báo cáo hiển thị: 0 dòng thành công, 1 dòng lỗi (dòng 3: name không được rỗng).

## Actual result
Hệ thống báo lỗi dòng 3 bị thiếu tên sản phẩm nhưng vẫn thực hiện import thành công các sản phẩm khác ở dòng 2 và dòng 4 mà không rollback toàn bộ.
