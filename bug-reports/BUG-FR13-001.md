# BUG-FR13-001: Dashboard hiển thị sai tổng doanh thu cho các tập dữ liệu đơn hàng

## Found by Test Case
TC-FR13-DT-002, TC-FR13-DT-003, TC-FR13-DT-004

## Requirement liên quan
FR-13

## Severity / Priority
High / P2

Lý do: FR-13 yêu cầu Dashboard hiển thị tổng doanh thu bằng tổng `total_amount` của các đơn có `status = 'delivered'`. Chỉ số doanh thu là thông tin chính của Dashboard Admin; kết quả sai trong nhiều miền dữ liệu làm Admin không thể tin cậy số liệu. Nên sửa trong vòng hiện tại.

## Environment
**Browser**: Chrome Version 149.0.7827.103  
**OS**: macOS Tahoe 26.5.1  
**URL**: Backend `http://localhost:3000`; Frontend Admin `http://localhost:5174/`; Frontend Web `http://localhost:5173/`  
**Build / Commit**: `0b0d2e9`  
**Ngày thực thi**: 30/06/2026  
**Tester**: 23127300

## Steps to reproduce

### Kịch bản TC-FR13-DT-002
1. Đăng nhập vào phân hệ Web Admin bằng tài khoản Admin.
2. Chuẩn bị môi trường test có đúng một đơn hàng với `status = 'delivered'` và `total_amount = 30,000,000 đ`.
3. Mở màn hình Dashboard.
4. Quan sát chỉ số tổng doanh thu.
5. Quan sát chỉ số tổng số đơn hàng.

### Kịch bản TC-FR13-DT-003
1. Đăng nhập vào phân hệ Web Admin bằng tài khoản Admin.
2. Chuẩn bị môi trường test có đúng hai đơn hàng, cả hai đều có `status = 'delivered'`.
3. Chuẩn bị đơn hàng 1 có `total_amount = 30,000,000 đ`.
4. Chuẩn bị đơn hàng 2 có `total_amount = 6,000,000 đ`.
5. Mở màn hình Dashboard.
6. Quan sát chỉ số tổng doanh thu.
7. Quan sát chỉ số tổng số đơn hàng.

### Kịch bản TC-FR13-DT-004
1. Đăng nhập vào phân hệ Web Admin bằng tài khoản Admin.
2. Chuẩn bị môi trường test có năm đơn hàng:
   - Đơn hàng 1: `delivered` / `45,000,000 đ`
   - Đơn hàng 2: `pending` / `28,000,000 đ`
   - Đơn hàng 3: `confirmed` / `6,000,000 đ`
   - Đơn hàng 4: `shipping` / `4,000,000 đ`
   - Đơn hàng 5: `canceled` / `30,000,000 đ`
3. Mở màn hình Dashboard.
4. Quan sát chỉ số tổng doanh thu.
5. Quan sát chỉ số tổng số đơn hàng.

## Expected result
- TC-FR13-DT-002: Dashboard hiển thị tổng doanh thu `30,000,000 đ` và tổng số đơn hàng `1`.
- TC-FR13-DT-003: Dashboard hiển thị tổng doanh thu `36,000,000 đ`, bằng `30,000,000 đ + 6,000,000 đ`, và tổng số đơn hàng `2`.
- TC-FR13-DT-004: Dashboard hiển thị tổng doanh thu `45,000,000 đ`, chỉ lấy `total_amount` của đơn `delivered` và không cộng `28,000,000 đ`, `6,000,000 đ`, `4,000,000 đ`, `30,000,000 đ`; tổng số đơn hàng hiển thị `5`.

## Actual result
- TC-FR13-DT-002: Doanh thu hiển thị `60,000,000 đ`.
- TC-FR13-DT-003: Doanh thu hiển thị `72,000,000 đ`.
- TC-FR13-DT-004: Doanh thu hiển thị `90,000,000 đ`.
