# TC-FR-02-002: HTML5 validation chặn email sai định dạng

## Requirement ID

FR-02

## Module / Test type / Technique

Login Web / Black-box Functional / Decision Table Testing, HTML5 Validation

## Preconditions

- Người dùng đang ở trang Đăng nhập
- Network log đang được ghi để quan sát request đăng nhập

## Test data

| Field    | Value           |
| -------- | --------------- |
| Email    | `invalid-email` |
| Mật khẩu | `Test1234!`     |

## Test steps

1. Nhập Email `invalid-email`
2. Nhập Mật khẩu `Test1234!`
3. Bấm nút Đăng nhập
4. Quan sát HTML5 validation và network log

## Expected result

Browser báo email sai định dạng bằng HTML5 validation, form không được submit và không có request đăng nhập được gửi tới backend.
