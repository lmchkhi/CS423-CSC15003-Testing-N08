# TC-FR-02-001: Trường Email sử dụng input type email

## Requirement ID

FR-02

## Module / Test type / Technique

Login Web / Black-box Functional / UI Inspection

## Preconditions

- Người dùng đang ở trang Đăng nhập
- Có thể sử dụng Browser Developer Tools để kiểm tra DOM

## Test data

| Field                   | Value          |
| ----------------------- | -------------- |
| Phần tử                 | Trường Email   |
| Thuộc tính cần kiểm tra | `type="email"` |

## Test steps

1. Mở trang Đăng nhập
2. Mở Developer Tools và chọn trường Email
3. Kiểm tra phần tử HTML tương ứng

## Expected result

Trường Email được render bằng phần tử input có thuộc tính `type="email"`.
