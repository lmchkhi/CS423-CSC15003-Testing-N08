# TC-FR-02-010: Khóa còn hiệu lực chặn cả credentials đúng và sai

## Requirement ID
FR-02

## Module / Test type / Technique
Login Web / Black-box Functional, Security / Decision Table Testing, State Transition Testing

## Preconditions
- Tài khoản `test@eshop.com` vừa bị khóa do ba lần sai liên tiếp
- Thời gian từ lúc khóa nhỏ hơn 30 giây
- Không khẳng định counter hoặc timer thay đổi sau request trong lúc khóa

## Test data
| Field | Value |
|---|---|
| Credentials đúng | `test@eshop.com` / `Test1234!` |
| Credentials sai | `test@eshop.com` / `Wrong@123` |

## Test steps
1. Trong thời gian khóa, gửi request với credentials đúng
2. Ghi nhận response và token nếu có
3. Khi khóa vẫn còn hiệu lực, gửi request với credentials sai
4. Ghi nhận response và token nếu có

## Expected result
Cả hai request đều bị từ chối và không trả JWT. Thông báo phù hợp với trạng thái khóa nhưng không tiết lộ credentials đúng hay sai hoặc chi tiết nội bộ.
