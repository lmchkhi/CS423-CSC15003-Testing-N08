# TC-FR-02-006: Lần đăng nhập sai thứ nhất chưa khóa tài khoản

## Requirement ID
FR-02

## Module / Test type / Technique
Login Web / Black-box Functional / Decision Table Testing, State Transition Testing

## Preconditions
- Tài khoản `test@eshop.com` tồn tại và chưa bị khóa
- Bắt đầu một chuỗi đăng nhập mới, chưa có lần sai liên tiếp

## Test data
| Field | Value |
|---|---|
| Email | `test@eshop.com` |
| Mật khẩu sai | `Wrong@123` |
| Mật khẩu đúng | `Test1234!` |

## Test steps
1. Đăng nhập một lần bằng mật khẩu sai
2. Ghi nhận thông báo và token nếu có
3. Ngay sau đó đăng nhập bằng mật khẩu đúng
4. Ghi nhận kết quả đăng nhập

## Expected result
Lần đăng nhập sai thất bại với lỗi phù hợp, không lộ chi tiết và không trả JWT. Lần đăng nhập đúng ngay sau đó thành công và trả JWT, chứng minh tài khoản chưa bị khóa sau một lần sai. Giá trị counter `1` chỉ được suy ra theo requirement, không quan sát trực tiếp trong black-box.
