# TC-FR-02-008: Lần đăng nhập sai thứ ba liên tiếp kích hoạt khóa

## Requirement ID
FR-02

## Module / Test type / Technique
Login Web / Black-box Functional / Decision Table Testing, Boundary Value Analysis

## Preconditions
- Tài khoản `test@eshop.com` tồn tại và chưa bị khóa
- Bắt đầu một chuỗi đăng nhập mới, chưa có lần sai liên tiếp
- Có đồng hồ bấm giờ để ghi nhận thời điểm bắt đầu khóa

## Test data
| Field | Value |
|---|---|
| Email | `test@eshop.com` |
| Mật khẩu sai | `Wrong@123` |
| Mật khẩu đúng | `Test1234!` |
| Thời gian khóa mong đợi | `30 giây` |

## Test steps
1. Đăng nhập sai ba lần liên tiếp
2. Bắt đầu tính thời gian tại phản hồi của lần sai thứ ba (`t0`)
3. Ngay sau đó thử đăng nhập bằng mật khẩu đúng
4. Ghi nhận phản hồi và token nếu có

## Expected result
Ba lần đăng nhập sai đều thất bại với lỗi phù hợp, không lộ chi tiết và không trả JWT. Sau lần sai thứ ba, đăng nhập bằng mật khẩu đúng vẫn bị từ chối và không trả JWT, chứng minh tài khoản đã chuyển sang trạng thái khóa.
