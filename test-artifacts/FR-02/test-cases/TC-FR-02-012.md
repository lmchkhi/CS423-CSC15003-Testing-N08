# TC-FR-02-012: Đăng nhập lại được sau 30 giây khóa

## Requirement ID
FR-02

## Module / Test type / Technique
Login Web / Black-box Functional / Decision Table Testing, Boundary Value Analysis

## Preconditions
- Tài khoản `test@eshop.com` vừa bị khóa sau ba lần đăng nhập sai liên tiếp
- Có đồng hồ bấm giờ

## Test data
| Field | Value |
|---|---|
| Thời điểm thử | Ngay sau khi đủ 30 giây, ví dụ khoảng `31 giây` |
| Email | `test@eshop.com` |
| Mật khẩu đúng | `Test1234!` |

## Test steps
1. Bắt đầu đồng hồ tại phản hồi của lần đăng nhập sai thứ ba (`t0`)
2. Chờ qua mốc 30 giây, ví dụ đến khoảng `t0 + 31 giây`
3. Đăng nhập bằng mật khẩu đúng
4. Ghi nhận phản hồi và token

## Expected result
Khóa 30 giây đã hết hiệu lực; đăng nhập thành công và hệ thống trả về JWT Token không rỗng.
