# TC-FR-02-007: Lần đăng nhập sai thứ hai liên tiếp vẫn chưa khóa

## Requirement ID
FR-02

## Module / Test type / Technique
Login Web / Black-box Functional / Decision Table Testing, Boundary Value Analysis

## Preconditions
- Tài khoản `test@eshop.com` tồn tại và chưa bị khóa
- Bắt đầu một chuỗi đăng nhập mới, chưa có lần sai liên tiếp

## Test data
| Field | Value |
|---|---|
| Email | `test@eshop.com` |
| Mật khẩu sai | `Wrong@123` |
| Mật khẩu đúng | `Test1234!` |

## Test steps
1. Đăng nhập sai lần thứ nhất
2. Đăng nhập sai lần thứ hai liên tiếp
3. Ghi nhận phản hồi của cả hai lần
4. Ngay sau đó đăng nhập bằng mật khẩu đúng

## Expected result
Cả hai lần sai đều thất bại với lỗi an toàn và không trả JWT. Lần đăng nhập đúng tiếp theo thành công, chứng minh tài khoản chưa bị khóa ở biên `n-1`. Giá trị counter `2` chỉ được suy ra theo requirement.
