# TC-FR-02-004: Client lưu JWT sau đăng nhập thành công

## Requirement ID

FR-02

## Module / Test type / Technique

Login Web / Black-box Functional / Functional Testing, Security Testing

## Preconditions

- Tài khoản `test@eshop.com` tồn tại và chưa bị khóa
- Có thể quan sát response đăng nhập và client storage/state bằng Developer Tools

## Test data

| Field            | Value                        |
| ---------------- | ---------------------------- |
| Email            | `test@eshop.com`             |
| Mật khẩu         | `Test1234!`                  |
| Token tham chiếu | JWT trong response đăng nhập |

## Test steps

1. Đăng nhập bằng tài khoản hợp lệ
2. Ghi lại JWT từ response đăng nhập
3. Kiểm tra cơ chế lưu trữ/state xác thực phía client
4. So sánh token phía client với token trong response

## Expected result

Client lưu đúng JWT nhận được sau đăng nhập để dùng cho các request cần xác thực. Requirement không bắt buộc một cơ chế lưu cụ thể như `localStorage` hay `sessionStorage`.
