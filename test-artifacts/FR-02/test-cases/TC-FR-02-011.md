# TC-FR-02-011: Tài khoản vẫn bị khóa ngay trước mốc 30 giây

## Requirement ID
FR-02

## Module / Test type / Technique
Login Web / Black-box Functional / Boundary Value Analysis, State Transition Testing

## Preconditions
- Tài khoản `test@eshop.com` vừa bị khóa sau ba lần đăng nhập sai liên tiếp
- Có đồng hồ bấm giờ

## Test data
| Field | Value |
|---|---|
| Thời điểm thử | Khoảng `29 giây` sau lần sai thứ ba |
| Email | `test@eshop.com` |
| Mật khẩu đúng | `Test1234!` |

## Test steps
1. Bắt đầu đồng hồ tại phản hồi của lần đăng nhập sai thứ ba (`t0`)
2. Chờ đến khoảng `t0 + 29 giây`
3. Đăng nhập bằng mật khẩu đúng
4. Ghi nhận phản hồi và token nếu có

## Expected result
Tài khoản vẫn đang khóa; đăng nhập bị từ chối bằng lỗi phù hợp và không trả JWT.
