# TC-FR-02-005: Client gắn Bearer token vào request cần xác thực

## Requirement ID
FR-02

## Module / Test type / Technique
Authenticated Client Requests / Black-box Functional / Functional Testing, Security Testing

## Preconditions
- Người dùng đã đăng nhập và client đang lưu JWT hợp lệ
- Network log đang được ghi
- Có thể mở ít nhất một chức năng yêu cầu xác thực trong phạm vi test

## Test data
| Field | Value |
|---|---|
| Header mong đợi | `Authorization: Bearer <token>` |
| Phạm vi quan sát | Mọi request cần xác thực phát sinh trong flow được chọn |
| Token | JWT nhận được khi đăng nhập |

## Test steps
1. Sau khi đăng nhập, mở từng chức năng yêu cầu xác thực thuộc phạm vi test
2. Ghi nhận mọi request cần xác thực phát sinh trong Network panel
3. Kiểm tra request headers của từng request
4. So sánh Bearer token với JWT đã lưu phía client

## Expected result
Mỗi request cần xác thực đều có đúng một header `Authorization` theo dạng `Bearer <token>` và token khớp JWT đã lưu. Không đưa token vào URL hoặc request body thay cho header.
