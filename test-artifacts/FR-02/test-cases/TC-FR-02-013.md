# TC-FR-02-013: Đăng nhập thành công kết thúc chuỗi sai liên tiếp

## Requirement ID
FR-02

## Module / Test type / Technique
Login Web / Black-box Functional / State Transition Testing

## Preconditions
- Tài khoản `test@eshop.com` tồn tại và chưa bị khóa
- Bắt đầu một chuỗi đăng nhập mới, chưa có lần sai liên tiếp
- Áp dụng giả định AQ-01: đăng nhập thành công kết thúc chuỗi thất bại liên tiếp

## Test data
| Field | Value |
|---|---|
| Email | `test@eshop.com` |
| Mật khẩu đúng | `Test1234!` |
| Mật khẩu sai | `Wrong@123` |

## Test steps
1. Đăng nhập sai hai lần liên tiếp
2. Đăng nhập bằng mật khẩu đúng và xác nhận thành công
3. Kết thúc phiên đăng nhập
4. Đăng nhập sai thêm hai lần liên tiếp
5. Đăng nhập lại bằng mật khẩu đúng
6. Ghi nhận kết quả của lần đăng nhập cuối

## Expected result
Lần đăng nhập đúng ở giữa kết thúc chuỗi sai trước đó. Sau hai lần sai thuộc chuỗi mới, lần đăng nhập đúng cuối cùng vẫn thành công và trả JWT, chứng minh tài khoản chưa bị khóa.
