# TC-FR-02-009: Lỗi đăng nhập không tiết lộ sự tồn tại tài khoản

## Requirement ID
FR-02

## Module / Test type / Technique
Login Web / Black-box Security / Security Testing

## Preconditions
- Tài khoản `test@eshop.com` tồn tại và chưa bị khóa
- Email `not-registered@example.com` không tồn tại
- Các request được thực hiện trong cùng điều kiện môi trường

## Test data
| Field | Value |
|---|---|
| Trường hợp A | `test@eshop.com` / `Wrong@123` |
| Trường hợp B | `not-registered@example.com` / `Wrong@123` |

## Test steps
1. Gửi đăng nhập với email tồn tại và mật khẩu sai
2. Ghi nhận status, cấu trúc response và thông báo lỗi
3. Gửi đăng nhập với email không tồn tại
4. Ghi nhận status, cấu trúc response và thông báo lỗi
5. So sánh hai phản hồi

## Expected result
Cả hai request đều thất bại, không trả JWT và dùng phản hồi lỗi cùng lớp, không cho biết email có tồn tại hay mật khẩu sai. Response không chứa stack trace, câu lệnh truy vấn hoặc chi tiết nội bộ.
