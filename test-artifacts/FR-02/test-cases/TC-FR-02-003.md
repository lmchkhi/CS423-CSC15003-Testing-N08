# TC-FR-02-003: Đăng nhập thành công trả về JWT Token

## Requirement ID

FR-02

## Module / Test type / Technique

Login Web / Black-box Functional / Decision Table Testing

## Preconditions

- Tài khoản `test@eshop.com` tồn tại, chưa bị khóa và có mật khẩu `Test1234!`
- Bộ đếm thất bại của tài khoản nhỏ hơn 3

## Test data

| Field | Value |
|---|---|
| Email | `test@eshop.com` |
| Mật khẩu | `Test1234!` |

## Test steps

1. Mở trang Đăng nhập và bật Network panel của trình duyệt
2. Đăng nhập với Email và Mật khẩu đã nêu
3. Chọn request đăng nhập vừa phát sinh và quan sát response
4. Lấy JWT Token từ response
5. Kiểm tra token tồn tại, không rỗng và có cấu trúc JWT ba phần phân cách bằng dấu chấm

## Expected result

Đăng nhập thành công; response trả về một JWT Token không rỗng. Không có lỗi xác thực hoặc trạng thái khóa.
